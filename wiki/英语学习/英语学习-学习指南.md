# 英语学习指南

[[wiki/英语学习/00-索引|返回英语学习索引]] · [[wiki/英语学习/英语学习-知识地图|查看知识地图]]

本页“原书”指廖恒《学好英语，4个月就够了》。词汇记忆的补充入口另整理康文捷的十种方法，来源与建议标注在对应页面。

## 按原书思路开始

1. **目标倒推**：写下要完成的英语任务，例如读懂技术文档、参与软件问题讨论或备考。根据任务选一段真实材料；备考用真题，工作用实际文档，日常交流用相应对话。[原书词句篇][units] [原书选文][selection]
2. **首次试做**：不查答案先读或听，试着说出主旨、关键关系和卡点。原书建议选初看约能理解八成的材料；这只是选难度的起点。[原书选文][selection]
3. **分阶段集中补缺口**：每次只定一个主攻问题。声音辨不清，练音标、拼读与音文对应；词义不清，查语境、词族和介词，并核对自然搭配；句子看不懂，先找各分句的动词组合，再补词类、句型、从句与非谓语；整篇抓不住，做五步精读。[原书集中训练][focus] [原书语法框架][grammar]
4. **回到任务检验**：用原材料完成精读或精听，再换相近难度的新材料独立复述、回答或表达。能在新材料中使用才勾选[[wiki/英语学习/英语学习-知识地图|知识地图]]；旧材料熟悉不等于掌握。

集中学语法时可沿原书次序：分句谓语 → 两类基本句型 → 十类词性 → 作者选的八种时态形式 → 主被动 → 从句 → 非谓语、词法、句式、常用句型与虚拟表达。“第几天”是书的教学编排，不是学会所需时间。[原书语法框架][grammar]

词、句、篇是分析层级，不必等所有语法学完才开始读、听、说、写。原书还强调口语需要开口练习。[原书10问][questions]

## 读写练习

精读先试读：原书的“80%原则”是指初看约能读懂文章八成，仍有可攻克的难点；它与书中建议的“80%时间精读、20%时间泛读”不是同一个指标，后者也不是必须遵守的配额。[原书选文][selection] [原书时间分配][readingmix]

按原书[五步精读法][reading]整理：

| 步骤 | 操作与检查 |
| --- | --- |
| 通读大意 | 先理解主题和场景，用一句话说明文章在谈什么 |
| 分析篇章 | 找观点、解释、例子及段落关系，不把每个首句都机械认作主题句 |
| 细读句词 | 只围绕真实障碍查词义、搭配、结构；把信息接回整句 |
| 回译 | 先译成中文，再遮住英文译回；对照检查意思、语法、搭配和信息重点 |
| 复述 | 不看原文口头重述主旨、段落要点和逻辑；困难时可先列关键词，再录音检查遗漏 |

原书要求回译尽量复现原句。检查时区分意思变化、语法错误、搭配问题和另一种正确表达，**与原文不同不自动算错**。

练完换人物、时间或对象，再表达一次。容易的材料用于泛读，练连续理解。

## 听力练习

原书“四轮精听法”可直接用一段带原文的短录音练习：[原书方法][listening]

1. 正常速度听全文，只记录主旨和关键点。
2. 逐句暂停听写；听不出的地方标记，不无限重复。
3. 再听全文，修正听写；随后对照原文，标出写错、听错和没听清的位置。
4. 只细听出错的句子，查明是声音没认出，还是看文字也不懂。

再换一段新录音检验迁移。泛听用较容易的材料练连续理解，不逐句暂停。弱读、连读会影响词语识别，结合录音和原文核对。[连续语流依据][speech]

## 怎样判断进步

| 检查 | 通过表现 |
| --- | --- |
| 理解 | 能解释关系，不漏否定、条件、指代等关键信息 |
| 独立使用 | 不看原句完成改写、复述或场景表达 |
| 新材料迁移 | 换例子或录音，首次接触仍能完成相同任务 |

听力、阅读和表达分开判断。再次卡住时，取消相应勾选，留下一个错例及修正理由。

## 来源与边界

原书的“四个月”、固定学习量与速成效果不作保证。“一句一个谓语”不能套到整句：分析时找各分句的限定动词及助动词组合，也留意并列谓语；原书“八时态”是入门选取，非完整清单。词义的共同核心是查词线索，派生词的词性正确也不保证搭配自然，仍需核对词典和语境。诊断表、新材料复测为学习建议。语法参考见 [British Council][verb]、[Cambridge][finite]；[[raw/links/2026-10-22-英语学习地图-来源与核验范围|来源记录]]保存初版核验范围，最新已核对的原书段落直接链接在本页与地图中。
