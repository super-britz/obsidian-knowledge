# 元音组合读音规律

[[wiki/英语学习/音标学习/00-索引|返回音标学习索引]]

**一个字母组合一行；情况栏给出条件（词中/词尾、重读/非重读、c 后、l/r 后、ll 双写）即可预测，标"无规律"的按词记，例词即整组；X~Y 表示两种读音（或其中间值）。双胞胎规则：i/u 管词中、y/w 管词尾。** 机制见[[wiki/英语学习/音标学习/元音字母-读音规律|元音字母读音规律]]，低频稀客与例外词附在各表后。

## a 的组合

单字母默认（闭音节 /æ/、非重读 /ə/）见字母页。

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ai** | /eɪ/ 多数：rain, train, wait |
| **ay** | /eɪ/ 词尾：day, play, stay |
| **au** | /ɔː/ 词中：autumn, cause, pause |
| **aw** | /ɔː/ 词尾为主：law, draw, saw |
| **augh** | /ɔː/ au + 哑音 gh：taught, daughter |
| **air** | /eə/（美 /er/）：air, hair, pair |
| **are** | /eə/（美 /er/）词尾：care, share |
| **ar** | /ɑː/ 重读：car, farm |
| **arr** | 1. /ær/ 重读（双写锁短）：carry, marry<br>2. /ər/ 非重读：arrive, arrange |
| **al** | 1. /ɔːl/ ll 双写：ball, small<br>2. /ɔːk/ 哑音 l（alk）：talk, walk<br>3. /æl/ 无 ll/lk 时默认：album, salad<br>4. /əl/ 词尾后缀：animal, capital |
| **aur** | /ɔːr/ au 不受 r 改写：Laura, dinosaur |
| **wa** | /ɒ/（美 /ɑ/）w 后：want, wash, what |
| **war** | /ɔː/ w+ar：warm, war |
| **a_e** | /eɪ/ magic e：name, cake |

低频参考：ai 非重读 -ain /ɪ/（mountain, captain, certain）、aa（Aaron）、ae（aesthetic）、ao（chaos）、eau（beauty）、aigh（straight）、英音 broad A（class 组）、alt/als 半暗化（salt 组，反例 alcohol）、aire（millionaire）、词尾 -ar/-er/-or 一律 /ər/（grammar）、plaid、draught、ah/aye/baa。

例外词卡：said、says、again、laugh、aunt、any/many、have/give、one/once/wonder、calm/palm/half、salmon、aisle、because、gauge、yacht、are（动词 /ɑːr/）、bass（/beɪs|bæs/）、vase。

## e 的组合

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ee** | /iː/ 几乎全部：see, week, green |
| **ea** | 1. /iː/ 多数：eat, sea, teacher<br>2. /e/ 无规律：head, bread, weather<br>3. /eɪ/ 无规律：great, break, steak |
| **ear** | 1. /ɪə/ 多数：hear, near, year<br>2. /ɜː/ 无规律：learn, early, earth<br>3. /eə/（美 /er/）无规律：bear, pear, wear |
| **ei** | 1. /iː/ c 后：receive, ceiling<br>2. /eɪ/ 无规律：vein, reign |
| **ey** | 1. /eɪ/ 无规律：they, grey, obey<br>2. /i/ 词尾多见，无规律：money, honey |
| **ew** | 1. /juː/ 默认：few, new<br>2. /uː/ l、r 后：grew, flew |
| **eigh** | /eɪ/ 多数：eight, weigh, neighbor |
| **eer** | /ɪə/：deer, cheer |
| **ere** | /ɪə/ 多数：here, sincere（there/where → /eə/，were → /wɜːr/） |
| **el** | /əl/ 词尾非重读：camel, travel |

低频参考：eo（people）、sew、ewe、e+rr 双写（merry）。

例外词卡：heart、eye、key、been（美 /bɪn/）、their、height。

## i 的组合

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ie** | 1. /iː/ 词中重读：believe, field, chief<br>2. /aɪ/ 重读词尾（单音节与 -ied）：pie, lie, tried<br>3. /i/ 非重读词尾：movie, cookie, Charlie；复数 -ies：studies<br>4. /aɪə/ 后接元音：science, quiet, diet |
| **igh** | /aɪ/ 哑音 gh：light, night, high |
| **ir** | /ɜː/ 重读：bird, girl, first |
| **irr** | /ɪ/ 双写锁短：mirror |
| **ire** | /aɪə/ 词尾：fire, hire, tired |
| **ia** | 1. /aɪə/ 重读：dial, giant, diamond<br>2. /iə~ə/ 非重读：media, special |
| **io** | 1. /aɪə/ 重读：violin, violent<br>2. /iə~ə/ 非重读：radio, nation |
| **ing** | /ɪŋ/ 后缀：sing, doing |
| **ind / ild** | /aɪ/ 长化：child, find, wild |
| **iu** | /iəm/ -ium 后缀：medium, stadium |

低频参考：ign（sign）、ier 重读（fierce）与非重读 /iə/（premier, chandelier）、-ieth（twentieth）、soldier、iew（view）、i 滑音 /j/（million）。

例外词卡：friend。

## o 的组合

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **oa** | /oʊ/ 多数：boat, road, coach |
| **oi** | /ɔɪ/ 词中：coin, noise, point |
| **oy** | /ɔɪ/ 词尾：boy, enjoy, toy |
| **oo** | 1. /uː/ 多数：food, school, moon<br>2. /ʊ/ 无硬规律（k、d 前居多）：book, look, good |
| **ou** | 1. /aʊ/ 多数：house, out, cloud<br>2. /uː/ 无规律：soup, group<br>3. /ʊ/ 无规律（情态组）：could, would, should<br>4. /ʌ/ 无规律：touch, young, country |
| **ow** | 1. /aʊ/ 无规律：cow, down, how<br>2. /oʊ/ 无规律：snow, know, show |
| **or** | /ɔː/ 重读：horse, morning |
| **ore** | /ɔːr/ 词尾：more, store, before |
| **oor** | /ɔːr/ 词尾：door, floor |
| **oar** | /ɔːr/ 词中：board, roar |
| **our** | 1. /ɔːr/ 多数：four, your<br>2. /ɜː/ 无规律：journey<br>3. /aʊə/ 无规律：hour |
| **old** | /oʊld/ 长化：cold, old, hold |
| **ost** | /oʊst/ 多数长化：most, post（反例 cost, lost） |
| **tion** | /ʃən/ 后缀：nation, station |
| **sion** | 1. /ʒən/ 元音后：vision, television<br>2. /ʃən/ n 后及 ssion：tension, mission |
| **oe** | /oʊ/ 词尾：toe, goes, shoes |

低频参考：broad、choir、ough 七读（though /oʊ/、through /uː/、tough /ʌf/、cough /ɒf/、bough /aʊ/、bought /ɔː/、thorough /ə/）。

例外词卡：does、blood、flood、cost/lost、done、gone。

## u 的组合

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ue** | 1. /juː/ 默认：due, value<br>2. /uː/ l、r 后（滑音被吞）：true, blue |
| **ui** | /uː/ 几乎全部（r、l、dʒ 后无滑音）：fruit, juice, suit（英 /sjuːt/ 可带滑音） |
| **ur** | /ɜː/ 重读：turn, nurse |
| **ure** | /ʊə/（美 /ʊr/）词尾：cure, pure |
| **ture** | /tʃər/ 后缀：picture, nature |
| **sure** | /ʒər/ 后缀：pleasure, measure |
| **qu** | /kw/ 固定，后接元音按 w 规律：quick, quality |
| **uy** | /aɪ/ 词尾：buy, guy |
| **gu** | /ɡ/ e/i 前哑音 u；词尾 -gue 同：guess, guitar；tongue |

低频参考：qua/gua（language、guard、persuade）、ui 变体（guide、build）、uu（vacuum）。

例外词卡：queue、sure。
