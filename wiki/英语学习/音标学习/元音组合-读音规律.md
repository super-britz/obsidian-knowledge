# 元音组合读音规律

[[wiki/英语学习/音标学习/00-索引|返回音标学习索引]]

**本页是"见词能读"的清单页：一个字母组合一行，读音、情况和单词放在同一单元格里，多读组合以 1. 2. 3. 分行（`<br>` 换行）。** 机制不在此重复——r 家族、w 暗化、大推移等见[[wiki/英语学习/音标学习/元音字母-读音规律|元音字母读音规律]]。

**情况一栏的约定：写出条件（词中/词尾、重读/非重读、c 后、l/r 后、ll 双写等）的读音可以由拼写预测；标"无规律"的只能按词记，所列例词即该组代表，没有可推的规则。**

每个字母分三层：**核心表**（常见组合，当规律记）、**参考区**（只覆盖三五个词，遇到整词记）、**例外词卡**（高频例外，靠使用覆盖）。

## 1 总钥匙

1. **双胞胎分工**：同一个音两种拼法，i/u 管词中、y/w 管词尾（英语词尾不写 i、u）——ai/ay、au/aw、ei/ey、oi/oy 四对全如此。
2. **r 控制串**：单 r 吞短元音变卷舌（机制见[[wiki/英语学习/音标学习/元音字母-读音规律#2 邻居层 r 家族与 w 捣乱|r 家族]]）；双 rr 锁回短音（carry）；长音支是 air/are（/eə/，美 /er/）；aur 不受 r 改写（au 完好 + r）。
3. **l 是暗化剂**：a 在 l 前趋向 /ɔː/（与 w 暗化同族）；词尾 -al 后缀按弱化读 /əl/。
4. **哑音 gh 作证**：augh、eigh、igh 里的 gh 曾发声，今哑，拼写留证。
5. **非重读弱化对组合同样生效**：mount**ai**n → /ɪ/，-tion → /ə/，框架第一层无处不在。
6. **稀客走词源层**：aa/ae/ao/eau/aigh 只活在借词与专名里，见[[wiki/英语学习/音标学习/元音字母-读音规律#3 词源层 借词的两档|借词两档]]。

## 2 a 的组合

单字母三条默认（重读闭音节 /æ/、magic e /eɪ/、非重读 /ə/ 及 -age/-ate 词尾 /ɪ/）见[[wiki/英语学习/音标学习/元音字母-读音规律|元音字母页]]，下表只列组合。

### 核心表（常见组合）

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ai** | /eɪ/ 多数：rain, train, wait |
| **ay** | /eɪ/ 词尾：day, play, stay |
| **au** | /ɔː/ 词中：autumn, cause, pause |
| **aw** | /ɔː/ 词尾为主：law, draw, saw |
| **augh** | /ɔː/ au + 哑音 gh：taught, daughter |
| **air** | /eə/（美 /er/）：air, hair, pair |
| **are** | /eə/（美 /er/）词尾：care, share, rare |
| **ar** | /ɑː/ 重读：car, farm, star |
| **arr** | 1. /ær/ 重读（双写锁短）：carry, marry<br>2. /ər/ 非重读：arrive, arrange |
| **al** | 1. /ɔːl/ ll 双写，可靠：ball, small<br>2. /ɔːk/ 哑音 l（alk）：talk, walk<br>3. /æl/ 无 ll/lk 时按默认闭音节：album, salad<br>4. /əl/ 词尾后缀：animal, capital |
| **aur** | /ɔːr/ au 不受 r 改写：Laura, dinosaur |
| **wa** | /ɒ/（美 /ɑ/）w 后：want, wash, what |
| **war** | /ɔː/ w+ar：warm, war |
| **a_e** | /eɪ/ magic e：name, cake |

同一个 /eə/ 四种拼法：air、are、ear（bear、pear，归 e 节）、ere（there、where；here 是 /ɪə/ 不同道）。/ɔː/ 在 a 家族四种：au、aw、augh、al。

### 参考区（查得到即可，不背）

| 组合 | 读音 | 例词与备注 |
| --- | --- | --- |
| aa | /eə~ɑː/ | Aaron, aardvark |
| ae | /iː~e/ | aesthetic（美式常改拼 esthetic）、aeroplane（美式用 airplane） |
| ao | /eɪ~oʊ/，不统一 | ch**ao**s /ˈkeɪɒs/、phar**ao**h、gaol /dʒeɪl/ |
| eau | /juː~ʊ~oʊ/ | beauty, bureau, plateau，按词记 |
| aigh | /eɪ/ | straight 一个词 |
| 英音 broad A | 英 /ɑː/，美 /æ/ | class, past, ask, bath, dance（学美音可忽略） |
| alt / als 半暗化 | 多数 /ɔː/，无硬规律，反例存在 | salt, false, always, also, alter；alcohol /ˈælkəhɒl/ |
| 哑音 l 组 | /ɑː/ 或 /æ/，分道 | calm, palm, almond, half（英）；salmon /ˈsæmən/ 留 /æ/ |
| aire 词尾 | /eər/（美 /er/） | million**aire**, questionn**aire**（air + 哑音 e） |
| 词尾 -ar / -er / -or | 一律弱读 /ər/ | gramm**ar**, doll**ar**, sug**ar**，与 pap**er**, doct**or** 同归宿 |
| ai 变体 | /æ/ | pl**ai**d /plæd/（苏格兰借词） |
| augh 变体 | 英 /ɑːf/ | dr**augh**t（美式改拼 draft 绕开它） |

边缘词认脸：ah /ɑː/、aye /aɪ/、baa /bɑː~bæ/（拟声，aa 不总读 /eə~ɑː/）。

### 例外词卡

said / says / again、laugh、aunt、any / many、have / give（哑音 e 陪 v 不施法）、one / once / wonder、calm / palm / half、salmon、aisle、because、gauge /ɡeɪdʒ/（au → /eɪ/ 孤例）、yacht /jɒt~jɑːt/、are（动词 /ɑːr/，-are 家族最高频例外）、bass（音乐 /beɪs/、鱼 /bæs/，同拼双音）、vase（英 /vɑːz/，美 /veɪs~væs/）——全是高频词，靠使用覆盖，不专门背表。

## 3 e 的组合

e 组合最大的坑是 **ea 一拼两读**（/iː/ 默认、/e/ 第二大组），两读之间无规律，只能按词记。

### 核心表（常见组合）

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ee** | /iː/ 几乎全部：see, week, green |
| **ea** | 1. /iː/ 多数，默认先猜：eat, sea, teacher<br>2. /e/ 无规律，按词记：head, bread, weather<br>3. /eɪ/ 无规律，固定小词组：great, break, steak |
| **ear** | 1. /ɪə/ 多数，默认先猜：hear, near, year<br>2. /ɜː/ 无规律，按词记：learn, early, earth<br>3. /eə/（美 /er/）无规律，按词记：bear, pear, wear |
| **ei** | 1. /iː/ c 后（"i before e except after c"）：receive, ceiling<br>2. /eɪ/ 其余，无规律：vein, reign |
| **ey** | 1. /eɪ/ 无规律：they, grey, obey<br>2. /i/ 词尾多见，无规律：money, honey, valley |
| **ew** | 1. /juː/ 默认：few, new<br>2. /uː/ l、r 后：grew, flew |
| **eigh** | /eɪ/ 多数：eight, weigh, neighbor |
| **eer** | /ɪə/：deer, cheer |
| **ere** | /ɪə/ 多数：here, sincere（there/where → /eə/、were → /wɜːr/ 例外） |
| **el** | /əl/ 词尾：hotel, camel（与 -al 同归宿） |

### 参考区（查得到即可，不背）

| 组合 | 读音 | 例词与备注 |
| --- | --- | --- |
| eo | /iː~ə/ | people, pigeon, leopard（借词杂拼） |
| ew 变体 | /oʊ/；/juː/ | sew（孤例）；ewe |
| e+rr 双写 | /e/+r | merry, error（双写锁短通则） |

### 例外词卡

heart /hɑːt/（ea → /ɑː/ 孤例）、eye /aɪ/、key /kiː/（ey → /iː/）、been（英 /biːn/，美 /bɪn/）、their /ðeər/（ei → /eər/，超高频）、height /haɪt/（eigh 家唯一 /aɪ/）、friend（见 i 节）。

## 4 i 的组合

主线是"位置决定 ie"和"哑音 gh/gn 的历史遗存"。

### 核心表（常见组合）

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ie** | 1. /iː/ 词中：believe, field, chief<br>2. /aɪ/ 词尾：pie, lie, tried（两读互补不打架） |
| **igh** | /aɪ/ 哑音 gh：light, night, high |
| **ir** | /ɜː/ 重读：bird, girl, first |
| **irr** | /ɪ/ 双写锁短：mirror |
| **ire** | /aɪə/ 词尾：fire, hire, tired |
| **ia** | 1. /aɪə/ 重读：dial, giant, diamond<br>2. /iə~ə/ 非重读：media, special |
| **io** | 1. /aɪə/ 重读：violin, violent<br>2. /iə~ə/ 非重读：radio, nation |
| **ing** | /ɪŋ/ 后缀：sing, doing |
| **ind / ild** | /aɪ/ 长化：child, find, wild |
| **iu** | /juː~iəm/ -ium 后缀：medium, museum |

### 参考区（查得到即可，不背）

| 组合 | 读音 | 例词与备注 |
| --- | --- | --- |
| ign → /aɪn/（哑 gn） | /aɪn/ | sign, design, align；foreign（eign → /ən/） |
| ier | /ɪə/ | fierce, tier, frontier |
| ie + 元音 → /aɪ/ | /aɪə/ | science, society |
| ie → /ə/ | /ə/ | soldier |
| iew | /juː/ | view, review, interview（ie 退化成 /j/ + ew） |
| i 滑音化 | /j/ | million, onion, opinion（字母页 §5 已讲） |

### 例外词卡

friend /frend/（ie → /e/ 孤例级）。

## 5 o 的组合

最大的坑是 **oo 和 ow 各自一拼两读**，两组内部都无规律；ou 是变体最多的组合。

### 核心表（常见组合）

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **oa** | /oʊ/ 多数：boat, road, coach |
| **oi** | /ɔɪ/ 词中：coin, noise, point |
| **oy** | /ɔɪ/ 词尾：boy, enjoy, toy |
| **oo** | 1. /uː/ 多数，默认先猜：food, school, moon<br>2. /ʊ/ 无硬规律（k、d 前居多）：book, look, good |
| **ou** | 1. /aʊ/ 多数，默认先猜：house, out, cloud<br>2. /uː/ 无规律，按词记：soup, group<br>3. /ʊ/ 无规律，固定情态组：could, would, should<br>4. /ʌ/ 无规律，按词记：touch, young, country |
| **ow** | 1. /aʊ/ 无规律，按词记：cow, down, how<br>2. /oʊ/ 无规律，按词记：snow, know, show |
| **or** | /ɔː/ 重读：horse, morning |
| **ore** | /ɔːr/ 词尾：more, store, before |
| **oor** | /ɔːr/ 词尾：door, floor |
| **oar** | /ɔːr/ 词中：board, roar |
| **our** | 1. /ɔːr/ 多数，默认先猜：four, your<br>2. /ɜː/ 无规律：journey<br>3. /aʊə/ 无规律：hour |
| **old** | /oʊld/ 长化：cold, old, hold |
| **ost** | /oʊst/ 多数长化：most, post（反例 cost, lost） |
| **tion** | /ʃən/ 后缀：nation, station |
| **sion** | /ʒən/ 后缀；ssion → /ʃən/：television, decision；mission |
| **oe** | /oʊ/ 词尾：toe, goes, shoes |

### 参考区（查得到即可，不背）

| 组合 | 读音 | 例词与备注 |
| --- | --- | --- |
| oa 变体 | /ɔː/ | broad, abroad |
| oi 变体 | /waɪə/ | choir /ˈkwaɪər/ |
| ough（七读，整词记） | 各异 | though /oʊ/、through /uː/、tough /ʌf/、cough /ɒf/、bough /aʊ/、bought /ɔː/、thorough /ə/ |

### 例外词卡

does /dʌz/（oe → /ʌ/，超高频孤例）、broad、blood / flood（oo → /ʌ/）、could / would / should（高频助动词）、cost / lost（反长化）、done /dʌn/、gone。

## 6 u 的组合

u 的组合最少——它的主线（双轨长音、/w/ 血统、哑音 gu）都在单字母层。

### 核心表（常见组合）

| 组合 | 发音与情况（多读以 1. 2. 3. 分行） |
| --- | --- |
| **ue** | /uː~juː/ 词尾（l/r 后无滑音）：true, blue；due, value |
| **ui** | /uː~juː/ 词中：fruit, juice, suit |
| **ur** | /ɜː/ 重读：turn, nurse |
| **ure** | /ʊə/（美 /ʊr/）词尾：cure, pure |
| **ture** | /tʃər/ 后缀：picture, nature |
| **sure** | /ʒər/ 后缀：pleasure, measure |
| **qu** | /kw/ 固定（qu 后的元音按 w 规律走）：quick, quality |
| **uy** | /aɪ/ 词尾：buy, guy |
| **gu** | /ɡ/ e/i 前哑音 u；词尾 -gue 同：guess, guitar；tongue, league |

### 参考区（查得到即可，不背）

| 组合 | 读音 | 例词与备注 |
| --- | --- | --- |
| qua / gua 家族 | u 退化 /w/ 后按 a 规律 | language /ˈlæŋɡwɪdʒ/, guard /ɡɑːrd/, persuade /pərˈsweɪd/ |
| ui 变体 | /aɪ/；/ɪ/ | guide；build |
| uu | /juː/ | vacuum, continuum（稀有） |

### 例外词卡

queue /kjuː/（qu + ueue 杂糅孤例）、sure /ʃʊr~ʃɔːr/。

## 来源与范围

2026-10 与用户对话整理的教学归纳；组合清单按"第二字母遍历法"核对（拼写空间封闭可穷举，读音值因借词开放）。核心表只收常见组合，一个组合一行，多读以 1. 2. 3. 分行；情况栏只给可预测的条件，不可预测的明确标"无规律，按词记"。稀客与变体留在参考区，高频例外进词卡。例词读音以 [Cambridge 词典][pron] 为准。
