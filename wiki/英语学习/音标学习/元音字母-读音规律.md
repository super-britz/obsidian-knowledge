# 元音字母读音规律

[[wiki/英语学习/音标学习/00-索引|返回音标学习索引]]

**五个元音字母 a/e/i/o/u 在单词里读什么，由四层条件依次决定：重音 > 音节类型 > 邻居字母 > 词源。** 本页是总表与机制；规律只解决生词的"第一猜"，最终以词典录音核对（查法见[[wiki/英语学习/02-声音与词汇#1 字母、音素与音标|字母、音素与音标]]）。

## 1 默认轨道与 magic e

重读音节里，闭音节读短音，开音节或"辅音+哑音 e"（magic e）读长音。这张 5×2 的表是整个体系的骨架：

| 字母 | 重读闭音节 | 重读开音节 / magic e |
| --- | --- | --- |
| a | /æ/：c**a**t, h**a**nd | /eɪ/：n**a**me, t**a**-ble |
| e | /e/：b**e**d, t**e**n | /iː/：th**e**se, h**e** |
| i | /ɪ/：s**i**t, f**i**sh | /aɪ/：t**i**me, h**i** |
| o | /ɒ/（美 /ɑ/）：h**o**t, st**o**p | /oʊ/：h**o**me, n**o** |
| u | /ʌ/：b**u**s, r**u**n | /juː/：c**u**te, **u**se |

**非重读一律弱化为 /ə/**（**a**bout, op**e**n, t**o**day, s**u**pport；后缀 -tion/-ture/-sure 全体适用）——这是全页最硬的一条规律，几乎无例外。

**magic e 的四个职务**（词尾哑音 e 不发音但在干活）：

1. 让前面的元音读字母音（make 里 a → /eɪ/，本页骨架表的右列全靠它）；
2. 软化 c、g：face /s/、large /dʒ/（对比 cat、game）；
3. 让 th 由清变浊：bath /θ/ → bathe /ð/；
4. 给词尾的 v 作伴（英语单词几乎不许 v 裸着收尾）：have, give, love。

## 2 邻居层 r 家族与 w 捣乱

**r 家族**：r 在右边就吞掉前面的短元音变卷舌，五个元音字母全部收编，规律只有一条——变成哪个卷舌音取决于被吞的是谁：

| 组合             | 读音                         | 例词                                     |
| -------------- | -------------------------- | -------------------------------------- |
| a+r            | /ɑː/                       | c**ar**, f**ar**m                      |
| o+r            | /ɔː/                       | h**or**se, m**or**ning                 |
| e/i/u + r      | /ɜː/                       | h**er**, b**ir**d, t**ur**n            |
| 词尾 a+re      | /eə/（美 /er/）              | c**are**, sh**are**                    |
| 词尾 u+re      | /ʊə/（美 /ʊr/）              | c**ure**, t**our**                     |

词尾 -ere 组（here /ɪə/、there /eə/、were /wɜː/）分道无规律，整词记，其余词尾 re 组合留给"元音组合"篇。

**w 是元音的暗化剂**（同一条 w 干扰，四个受害者）：

| 组合 | 读音 | 例词 |
| --- | --- | --- |
| w+a | /ɒ/（美 /ɑ/） | w**a**nt, w**a**sh, wh**a**t |
| w+o | /ʌ/ 或 /ʊ/（分道无规律，整词记） | /ʌ/：w**o**nder, **o**ne；/ʊ/：w**o**lf, w**o**man |
| w+ar | /ɔː/ | w**ar**m, w**ar** |
| w+or | /ɜː/（连 r 都拦不住 w） | w**or**d, w**or**k, w**or**ld |

**其他邻居规则**：

- -ind / -ild 长化：闭音节默认短音，但 child、find、kind、wild 读 /aɪ/（组小，整组记）；
- 双写辅音锁短音：双辅音跨音节、前一音节闭合，元音回到短音默认值——单 r 卷舌（car /kɑː/）对双 rr（carry /ˈkæri/）；通用信号，apple、butter、mirror 同理；
- l、r、dʒ 后面 u 的长音丢滑音 → /uː/（rule, rude, June），英美口音都遵守；美音丢得更广：news /nuː/、Tuesday /ˈtuːz-/（英音保留 /njuː/、/ˈtjuː-/）。

ar/arr/al/aur 等"a + 辅音块"的完整清单见[[wiki/英语学习/音标学习/元音组合-读音规律|元音组合页]]，机制仍以本页为准。

## 3 词源层 借词的两档

- **已消化**（借得早，完全按固有规律读）：chase /tʃeɪs/、chair、very——看不出法国血统。
- **保留口音**（18–19 世纪晚近借词，法语轨道）：
  - 词尾 é / -et → /eɪ/：café, fiancé, ballet, buffet, bouquet, cliché；
  - 鼻化元音去鼻化 + 补 /n/：genre（英 /ˈʒɒnrə/，美 /ˈʒɑːnrə/）、encore、ensemble、envelope（英 /ˈɒn-/）；
  - g+e → /ʒ/：genre, massage, mirage, beige；
  - i → /iː/（读 /iː/ 的 i 几乎全是罗曼语借词）：police, machine, visa；对照 polite /pəˈlaɪt/ 走固有轨道；
  - 词尾弱 -e/-re → /ə/：genre, theatre, centre。
- **双轨摇摆词**（词典双双收录）：envelope 英 /ˈɒnvələʊp/ vs 美 /ˈenvəloʊp/（美音按闭音节走回默认轨道）；garage /ˈɡærɪdʒ/ ~ /ˈɡærɑːʒ/。

判断信号：看起来洋气、带重音符号、艺术生活领域的词，先怀疑法语轨道，词典核对优先级提前。

## 4 机制故事速查

每个故事只讲一次，解释上文的"为什么"：

| 故事 | 一句话 | 解释了什么 |
| --- | --- | --- |
| 元音大推移 | 15–17 世纪长元音大搬家，拼写没跟上 | i 的长音 /iː/ 裂化成 /aɪ/，把 /iː/ 让给 e（these）；o 的松长音裂化 /oʊ/（home），紧长音高化 /uː/（do, who, move）——两大变道组都是正规军 |
| u 展唇下移 | 17 世纪短 /ʊ/ 变 /ʌ/，一批词没赶上 | 三种遗产：u 留原装（bus）、u 词换 o 装（love, come）、残留旧音（put, push 读 /ʊ/） |
| 拉丁 u/v 同字 | u 带一半辅音血统 | 长音自带滑音 /juː/；qu/gu 里退化为 /w/（quick, language）；gu+e/i 里哑音保 g 硬音（guitar）——哑音 e 软化 c/g 的镜像 |
| 抄写换装 | 中古手写体 u/n/m/v 全是竖笔画，数不清 | u 词换 o 装：love, come, son, mother（o 读 /ʌ/ 的真相）；反向换装：busy/build 的 u → /ɪ/、bury → /e/ |
| 晚近借词 | 借得晚，口音没洗掉 | §3 全部；早借的已被消化成默认轨道 |

## 5 分字母速查

各字母完整读音清单；"默认"即 §1 骨架表两列，其余为变道。

### a：常见 9 种

| 读音           | 例词                                         | 条件                             |
| ------------ | ------------------------------------------ | ------------------------------ |
| /æ/          | c**a**t, h**a**nd, **a**pple               | 重读闭音节（默认）                      |
| /eɪ/         | n**a**me, c**a**ke                         | 开音节、magic e（默认长音）              |
| /ɑː/         | c**a**r, f**a**ther；英音 f**a**st, d**a**nce | a+r；历史长音词；英音 broad A（美音保留 /æ/） |
| /ɔː/         | b**a**ll, t**a**lk, w**a**r；英音 w**a**ter   | a+ll/a+lk；w+ar                 |
| /ɒ/（美 /ɑ/）   | w**a**nt, w**a**sh                         | w+a                            |
| /ə/          | **a**bout, banan**a**                      | 非重读                            |
| /ɪ/          | vill**a**ge, priv**a**te                   | 非重读 -age/-ate 词尾               |
| /eə/（美 /er/） | c**a**re, sh**a**re                        | a+re 词尾                        |
| /e/          | **a**ny, m**a**ny                          | 仅少数例外词，整词记                     |

冠词 a 本身就是两态活例：强调读 /eɪ/，句中弱读 /ə/。

### e：常见 5 种，另加 e+r

| 读音 | 例词 | 条件 |
| --- | --- | --- |
| /iː/ | h**e**, th**e**se | 重读开音节、e+辅音+哑音 e |
| /e/ | b**e**d, **e**gg | 重读闭音节（默认） |
| /ɪ/ | b**e**gin, r**e**port, want**e**d, danc**e**s | 非重读前缀 be-/re-/de-；/t,d/ 后的 -ed、嘶擦音后的 -es |
| /ə/ | op**e**n, tak**e**n, stud**e**nt | 非重读词尾 |
| 不发音 | mak**e**, lov**e**, list**e**n | 词尾哑音 e（四职务见 §1）；辅音+le（tab**le**） |
| /ɜː/（e+r） | h**er**, t**erm** | r 家族 |

-ed 词尾两态：wanted 里 e 读 /ɪ/，played 里不发音——条件是前面是否 /t/、/d/（详见[[wiki/英语学习/02-声音与词汇#2 拼读、拼写与词尾读音|词尾读音]]）。一词三态：telephone /ˈtelɪfoʊn/ = /e/ + /ɪ/ + 不发音。

### i：常见 5 种，另加 i+r

| 读音 | 例词 | 条件 |
| --- | --- | --- |
| /aɪ/ | t**i**me, l**i**ke, h**i**, **i**dea | 重读开音节、magic e |
| /ɪ/ | s**i**t, b**i**g | 重读闭音节（默认） |
| /iː/ | pol**i**ce, mach**i**ne, v**i**sa, sk**i** | 罗曼语借词（几乎唯一来源） |
| /i/ | c**i**ty, tax**i**, sorry | 非重读词尾（"happy 元音"，与词尾 y 同音） |
| /j/ | mill**i**on, on**i**on, op**i**nion | 非重读且后接元音（-ion/-ia），滑音化 |
| /ɜː/（i+r） | b**ir**d, g**ir**l | r 家族 |

一词两态：idea /aɪˈdɪə/ = /aɪ/ + /ɪ/。借词判别对照组：polite /pəˈlaɪt/（固有）vs police /pəˈliːs/（借词）。

### o：常见 7 种

| 读音 | 例词 | 条件 |
| --- | --- | --- |
| /ɒ/（美 /ɑ/） | h**o**t, b**o**x | 重读闭音节（默认） |
| /oʊ/ | h**o**me, th**o**se, **o**pen | 开音节、magic e（默认长音） |
| /ʌ/ | l**o**ve, c**o**me, m**o**ther, **o**ne | 历史变道：u 词换 o 装（§4） |
| /uː/ | d**o**, t**o**, wh**o**, m**o**ve | 历史变道：中古紧长 o 高化（§4） |
| /ə/ | t**o**day, c**o**nnect, acti**o**n | 非重读（-tion/-sion 永远 /ə/） |
| /ɔː/ | h**or**se, f**o**r | o+r |
| /ʊ/ | w**o**lf, w**o**man | 零星残留 |

一词三态：tomorrow /təˈmɒroʊ/ = /ə/ + /ɒ/ + /oʊ/。-ove 三分裂只能整词记：love /lʌv/、move /muːv/、stove /stoʊv/。孤例：women /ˈwɪmɪn/ 里 o 读 /ɪ/。

### u：常见 8 种

| 读音 | 例词 | 条件 |
| --- | --- | --- |
| /ʌ/ | b**u**s, c**u**p | 重读闭音节（默认） |
| /juː/ | c**u**te, m**u**s**i**c, st**u**dent | 开音节、magic e（默认长音，自带 /j/） |
| /uː/ | r**u**le, J**u**ne, fl**u**te | l/r/dʒ 后滑音被吞（§2） |
| /ʊ/ | p**u**t, f**u**ll, p**u**sh, s**u**gar | 历史残留组：没赶上展唇下移（§4） |
| /ə/ | s**u**pport, stat**u**s, pic**u**re | 非重读（-us/-um/-ture/-sure） |
| /ɜː/ | t**ur**n, n**ur**se | u+r |
| /ʊə/（美 /ʊr/） | c**ure**, p**ure**, t**our** | u+re 词尾 |
| /w/ | q**u**ick, q**u**iet, lang**u**age | q/g 后辅音血统现形（§4） |

零星：哑音 u 保 g 硬音（g**u**itar, g**u**est）；换装 busy/build → /ɪ/、bury → /e/；词尾日语/法语借词 /uː/~/juː/（tof**u**, men**u**）。一词三态：unusual /ʌnˈjuːʒuəl/。残留组无规律可推：up /ʌp/ vs put /pʊt/，整词记。

## 6 半元音 y

英语惯常说"五个元音字母，有时加上 y"——y 是 i 的替身演员：

- 非重读词尾 → /i/：c**i**ty 与 happ**y** 同音（i 那个"happy 元音"多半由 y 出演）；
- 重读开音节 → /aɪ/：m**y**, fl**y**, sk**y**；
- 重读闭音节 → /ɪ/：g**y**m, m**y**th。

y 的完整角色（含辅音 /j/：yes, yellow）并入后续"辅音"篇。

## 7 怎么用这套规律

1. 生词先按四层走一遍出"第一猜"：非重读吗？闭音节还是 magic e？旁边有 r/w/l 吗？看着像借词吗？
2. 必须记牢的硬规律四条：非重读 → /ə/；重读闭音节 → 默认短音；magic e → 长音；qu → /kw/。
3. 变道组（o 的 /ʌ//uː/、u 的 /ʊ/、换装词）整词记，但知道 §4 的"为什么"会比当随机例外记得牢——好在它们高度高频。
4. 第一猜之后永远用词典录音核对；规律解决概率，不解决终审。
