# 元音字母读音规律

[[wiki/英语学习/音标学习/00-索引|返回音标学习索引]]

**五个元音字母 a/e/i/o/u 在单词里读什么，主要看四件事：是否重读、闭音节还是开音节、前后是什么字母、是不是外来词。** 本页是总表；规律只解决生词的"第一猜"，最终以词典录音核对（查法见[[wiki/英语学习/02-声音与词汇#1 字母、音素与音标|字母、音素与音标]]）。

## 1 基本读法：闭音节短音、开音节长音

重读音节里，闭音节读短音，开音节或"辅音+哑音 e"（magic e）读长音。这张 5×2 的表是全部规律的基础：

| 字母 | 重读闭音节                       | 重读开音节 / magic e       |
| ---- | -------------------------------- | -------------------------- |
| a    | /æ/：c**a**t, h**a**nd           | /eɪ/：n**a**me, t**a**-ble |
| e    | /e/：b**e**d, t**e**n            | /iː/：th**e**se, h**e**    |
| i    | /ɪ/：s**i**t, f**i**sh           | /aɪ/：t**i**me, h**i**     |
| o    | /ɒ/（美 /ɑ/）：h**o**t, st**o**p | /oʊ/：h**o**me, n**o**     |
| u    | /ʌ/：b**u**s, r**u**n            | /juː/：c**u**te, **u**se   |

**非重读一律弱化为 /ə/**（**a**bout, op**e**n, t**o**day, s**u**pport；后缀 -tion/-ture/-sure 全体适用）——这是全页最硬的一条规律，几乎无例外。

**词尾哑音 e 的四个作用**（e 不发音，但在改变读音）：

1. 让前面的元音读字母音（make 里 a → /eɪ/，上表右列全靠它）；
2. 软化 c、g：face /s/、large /dʒ/（对比 cat、game）；
3. 让 th 由清变浊：bath /θ/ → bathe /ð/；
4. 给词尾的 v 作伴（英语单词几乎不许 v 裸着收尾）：have, give, love。

## 2 前后字母的影响：r、w、双写

**元音后接 r**：读音变成卷舌音，五个元音字母都适用，只有一条规律——变成哪个卷舌音取决于前面的元音：

| 组合         | 读音            | 例词                        |
| ------------ | --------------- | --------------------------- |
| ar           | /ɑː/            | c**ar**, f**ar**m           |
| or           | /ɔː/            | h**or**se, m**or**ning      |
| er / ir / ur | /ɜː/            | h**er**, b**ir**d, t**ur**n |
| are          | /eə/（美 /er/） | c**are**, sh**are**         |
| ure          | /ʊə/（美 /ʊr/） | c**ure**, t**our**          |

词尾 -ere 组（here /ɪə/、there /eə/、were /wɜː/）分道无规律，整词记，其余词尾 re 组合留给"元音组合"篇。

**w 会改变后面元音的读法**（四种情况）：

| 组合 | 读音                             | 例词                                               |
| ---- | -------------------------------- | -------------------------------------------------- |
| wa   | /ɒ/（美 /ɑ/）                    | w**a**nt, w**a**sh, wh**a**t                       |
| wo   | /ʌ/ 或 /ʊ/（分道无规律，整词记） | /ʌ/：w**o**nder, **o**ne；/ʊ/：w**o**lf, w**o**man |
| war  | /ɔː/                             | w**ar**m, w**ar**                                  |
| wor  | /ɜː/                             | w**or**d, w**or**k, w**or**ld                      |

**其他邻居规则**：

- -ind / -ild 长化：闭音节默认短音，但 child、find、kind、wild 读 /aɪ/（组小，整组记）；
- 双写辅音锁短音：双辅音跨音节、前一音节闭合，元音回到短音默认值——单 r 卷舌（car /kɑː/）对双 rr（carry /ˈkæri/）；通用信号，apple、butter、mirror 同理；
- l、r、dʒ 后面 u 的长音丢滑音 → /uː/（rule, rude, June），英美口音都遵守；美音丢得更广：news /nuː/、Tuesday /ˈtuːz-/（英音保留 /njuː/、/ˈtjuː-/）。

ar/arr/al/aur 等元音后接辅音的组合，完整清单见[[wiki/英语学习/音标学习/元音组合-读音规律|元音组合页]]，机制仍以本页为准。

## 3 外来词的读法

- **借得早的**：已完全按上面的规律读，如 chase /tʃeɪs/、chair、very——看不出是法语词。
- **借得晚的**（18–19 世纪，多来自法语，保留原来的读法）：
  - 词尾 é / -et → /eɪ/：café, fiancé, ballet, buffet, bouquet, cliché；
  - 鼻化元音去鼻化 + 补 /n/：genre（英 /ˈʒɒnrə/，美 /ˈʒɑːnrə/）、encore、ensemble、envelope（英 /ˈɒn-/）；
  - ge → /ʒ/：genre, massage, mirage, beige；
  - i → /iː/（读 /iː/ 的 i 几乎全是罗曼语借词）：police, machine, visa；对照 polite /pəˈlaɪt/ 按上面的规律读；
  - 词尾弱 -e/-re → /ə/：genre, theatre, centre。
- **两种读法并存的词**（词典都收录）：envelope 英 /ˈɒnvələʊp/ vs 美 /ˈenvəloʊp/（美音按闭音节规律读 /e/）；garage /ˈɡærɪdʒ/ ~ /ˈɡærɑːʒ/。

判断信号：看起来洋气、带重音符号、艺术生活领域的词，先怀疑是法语读法，词典核对优先级提前。

## 4 为什么会有这些例外（选读）

不想看可以跳过，不影响使用上面的规律：

| 故事          | 一句话                                | 解释了什么                                                                                                                                            |
| ------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 元音大推移    | 15–17 世纪长元音大搬家，拼写没跟上    | i 的长音 /iː/ 裂化成 /aɪ/，把 /iː/ 让给 e（these）；o 的松长音裂化 /oʊ/（home），紧长音高化 /uː/（do, who, move）——两组都是历史上的正常变化，不是乱来 |
| u 展唇下移    | 17 世纪短 /ʊ/ 变 /ʌ/，一批词没赶上    | 三种遗产：u 留原装（bus）、u 词换 o 装（love, come）、残留旧音（put, push 读 /ʊ/）                                                                    |
| 拉丁 u/v 同字 | u 带一半辅音血统                      | 长音自带滑音 /juː/；qu/gu 里退化为 /w/（quick, language）；gu 后接 e/i 时 u 不发音、g 读 /ɡ/（guitar）——哑音 e 软化 c/g 的镜像                        |
| 抄写换装      | 中古手写体 u/n/m/v 全是竖笔画，数不清 | u 词换 o 装：love, come, son, mother（o 读 /ʌ/ 的真相）；反向换装：busy/build 的 u → /ɪ/、bury → /e/                                                  |
| 晚近借词      | 借得晚，口音没洗掉                    | 外来词一节全部；早借的已按默认规律读                                                                                                                  |

## 5 分字母速查

各字母的全部读音，前三行对应三条基本规律：闭音节短音、开音节长音、非重读 /ə/；规律有多条时以 1. 2. 3. 分行；标"无规律"的整词记。

### a 的读音

| 读音            | 规律                                                                        | 例词                                          |
| --------------- | --------------------------------------------------------------------------- | --------------------------------------------- |
| /æ/             | 重读闭音节（默认）                                                          | c**a**t, h**a**nd, **a**pple                  |
| /eɪ/            | 开音节、magic e（默认长音）                                                 | n**a**me, c**a**ke                            |
| /ə/             | 非重读                                                                      | **a**bout, banan**a**                         |
| /ɑː/            | 1. ar<br>2. 英音 ss/st/sk/th 前（美音读 /æ/）<br>3. father 等无规律，整词记 | c**a**r, f**a**ther；英音 f**a**st, d**a**nce |
| /ɔː/            | 1. all/alk<br>2. war                                                        | b**a**ll, t**a**lk, w**a**r                   |
| /ɒ/（美 /ɑ/）   | wa                                                                          | w**a**nt, w**a**sh                            |
| /ɪ/             | 非重读 -age/-ate 词尾                                                       | vill**a**ge, priv**a**te                      |
| /eə/（美 /er/） | are 词尾                                                                    | c**a**re, sh**a**re                           |
| /e/             | 无规律，整词记                                                              | **a**ny, m**a**ny                             |

冠词 a 本身就是两态活例：强调读 /eɪ/，句中弱读 /ə/。

### e 的读音

| 读音   | 规律                                                           | 例词                                          |
| ------ | -------------------------------------------------------------- | --------------------------------------------- |
| /e/    | 重读闭音节（默认）                                             | b**e**d, **e**gg                              |
| /iː/   | 重读开音节、e_e 结构                                           | h**e**, th**e**se                             |
| /ə/    | 非重读词尾                                                     | op**e**n, tak**e**n, stud**e**nt              |
| /ɪ/    | 1. 非重读前缀 be-/re-/de-<br>2. /t,d/ 后的 -ed、嘶擦音后的 -es | b**e**gin, r**e**port, want**e**d, danc**e**s |
| 不发音 | 词尾哑音 e                                                     | mak**e**, lov**e**, list**e**n                |
| 不发音 | 辅音+le                                                        | tab**le**, litt**le**                         |
| /ɜː/   | er                                                             | h**er**, t**erm**                             |

-ed 词尾两态：wanted 里 e 读 /ɪ/，played 里不发音——条件是前面是否 /t/、/d/（详见[[wiki/英语学习/02-声音与词汇#2 拼读、拼写与词尾读音|词尾读音]]）。一词三态：telephone /ˈtelɪfoʊn/ = /e/ + /ɪ/ + 不发音。

### i 的读音

| 读音 | 规律                         | 例词                                       |
| ---- | ---------------------------- | ------------------------------------------ |
| /ɪ/  | 重读闭音节（默认）           | s**i**t, b**i**g, f**i**sh                 |
| /aɪ/ | 重读开音节、magic e          | t**i**me, l**i**ke, h**i**, **i**dea       |
| /ə/  | 非重读词中                   | poss**i**ble, penc**i**l                   |
| /iː/ | 罗曼语借词（几乎唯一来源）   | pol**i**ce, mach**i**ne, v**i**sa, sk**i** |
| /i/  | 非重读词尾（与词尾 y 同音）  | c**i**ty, tax**i**, sorry                  |
| /j/  | 非重读且后接元音（-ion/-ia） | mill**i**on, on**i**on, op**i**nion        |
| /ɜː/ | ir                           | b**ir**d, g**ir**l                         |

一词两态：idea /aɪˈdɪə/ = /aɪ/ + /ɪ/。借词判别对照组：polite /pəˈlaɪt/（固有）vs police /pəˈliːs/（借词）。

### o 的读音

| 读音          | 规律                           | 例词                                    |
| ------------- | ------------------------------ | --------------------------------------- |
| /ɒ/（美 /ɑ/） | 重读闭音节（默认）             | h**o**t, b**o**x                        |
| /oʊ/          | 开音节、magic e（默认长音）    | h**o**me, th**o**se, **o**pen           |
| /ə/           | 非重读（-tion/-sion 永远 /ə/） | t**o**day, c**o**nnect, acti**o**n      |
| /ʌ/           | 无规律，整词记                 | l**o**ve, c**o**me, m**o**ther, **o**ne |
| /uː/          | 无规律，整词记                 | d**o**, t**o**, wh**o**, m**o**ve       |
| /ɔː/          | or                             | h**or**se, f**o**r                      |
| /ʊ/           | 无规律，整词记                 | w**o**lf, w**o**man                     |

一词三态：tomorrow /təˈmɒroʊ/ = /ə/ + /ɒ/ + /oʊ/。-ove 三分裂只能整词记：love /lʌv/、move /muːv/、stove /stoʊv/。孤例：women /ˈwɪmɪn/ 里 o 读 /ɪ/。

### u 的读音

| 读音            | 规律                          | 例词                                   |
| --------------- | ----------------------------- | -------------------------------------- |
| /ʌ/             | 重读闭音节（默认）            | b**u**s, c**u**p, r**u**n              |
| /juː/           | 开音节、magic e               | c**u**te, m**u**sic, st**u**dent       |
| /ə/             | 非重读（-us/-um/-ture/-sure） | s**u**pport, stat**u**s, pic**u**re    |
| /uː/            | l、r、dʒ 后（不读 /juː/）     | r**u**le, J**u**ne, fl**u**te          |
| /ʊ/             | 无规律，整词记                | p**u**t, f**u**ll, p**u**sh, s**u**gar |
| /ɜː/            | ur                            | t**ur**n, n**ur**se                    |
| /ʊə/（美 /ʊr/） | ure 词尾                      | c**ure**, p**ure**, t**our**           |
| /w/             | q、g 后（qu 读 /kw/）         | q**u**ick, q**u**iet, lang**u**age     |

零星：哑音 u 保 g 读硬音（g**u**itar, g**u**est）；特殊词 busy/build → /ɪ/、bury → /e/；词尾日语/法语借词 /uː/~/juː/（tof**u**, men**u**）。一词三态：unusual /ʌnˈjuːʒuəl/。

## 6 半元音 y

英语常说"五个元音字母，有时加上 y"——y 常代替 i 出现在词尾：

- 非重读词尾 → /i/：c**i**ty 与 happ**y** 同音（i 那个"happy 元音"多半由 y 出演）；
- 重读开音节 → /aɪ/：m**y**, fl**y**, sk**y**；
- 重读闭音节 → /ɪ/：g**y**m, m**y**th。

y 的完整角色（含辅音 /j/：yes, yellow）并入后续"辅音"篇。

## 7 怎么用这套规律

1. 生词先按顺序问四个问题，得出"第一猜"：非重读吗？闭音节还是 magic e？旁边有 r/w/l 吗？像外来词吗？
2. 必须记牢的硬规律四条：非重读 → /ə/；重读闭音节 → 默认短音；magic e → 长音；qu → /kw/。
3. 无规律的读音组（o 的 /ʌ/ /uː/、u 的 /ʊ/）和 busy、bury 这类特殊词整词记；它们都很常用，见几次就记住了。
4. 第一猜之后永远用词典录音核对；规律解决概率，不解决终审。
