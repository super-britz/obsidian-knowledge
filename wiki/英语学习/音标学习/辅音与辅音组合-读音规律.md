# 辅音与辅音组合读音规律

[[wiki/英语学习/音标学习/00-索引|返回音标学习索引]]

**辅音比元音省心：多数单辅音一对一，双读集中在 c、g、s、x 和 ch、th、ng 几个组合上。** 一个组合一行，多读以 1. 2. 3. 分行；情况栏写条件即可预测，标"无规律"的整词记。已讲过的不重复：词尾 -ed/-s 见[[wiki/英语学习/02-声音与词汇#2 拼读、拼写与词尾读音|声音与词汇]]，-tion/-ture/-sion/-sure/-cial 见[[wiki/英语学习/音标学习/元音组合-读音规律|元音组合页]]，qu 后的元音读法见[[wiki/英语学习/音标学习/元音字母-读音规律|元音字母页]]。

## 1 单辅音

多数一对一，直接读：

| 字母 | 读音                                  | 例词            |
| ---- | ------------------------------------- | --------------- |
| b    | /b/                                   | book, table     |
| d    | /d/                                   | dog, read       |
| f    | /f/                                   | fish, life      |
| h    | /h/                                   | hat, home       |
| j    | /dʒ/                                  | jump, joke      |
| k    | /k/                                   | key, kite       |
| l    | /l/（元音前清晰、音节尾偏暗，见下注） | leg, feel, milk |
| m    | /m/                                   | man, name       |
| n    | /n/                                   | net, nine       |
| p    | /p/                                   | pen, paper      |
| r    | /r/                                   | red, run        |
| t    | /t/                                   | top, water      |
| v    | /v/                                   | van, five       |
| w    | /w/（wr、wh 见组合表）                | wet, water      |
| y    | /j/                                   | yes, young, you |
| z    | /z/                                   | zoo, zero       |

注：l 有两个变体，词典都标 /l/ 不区分——音节首、元音前读清晰 l（leg, believe）；音节尾（含 milk、feeling 这类词中音节尾）读暗 l，舌尖照抵上齿龈、舌后部同时抬起，听起来低沉（feel, cold, table 的 -ble）。词尾的 l 别吞掉也别读成"欧"，舌尖要抵到上齿龈；美音几乎所有的 l 都偏暗。另外：双写辅音（pp、tt、ll 等）读音与单写相同，它的作用是锁住前面的短元音——见元音字母页。辅音簇（bl、tr、str 等）把各辅音直接连读，没有读音变化。

需要分情况的只有四个，其中只有 c 的规律可靠：

| 字母  | 发音与情况（多读以 1. 2. 3. 分行）                                                                                                                                                                                  |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **c** | 1. /k/ 多数：cat, cup, clock<br>2. /s/ e/i/y 前：city, face, cycle——规律可靠                                                                                                                                        |
| **g** | 1. /g/ 多数：go, big, game<br>2. /dʒ/ e/i/y 前：giant, page, magic——但 get、give、girl、tiger、begin 等本族词仍读 /g/，例外极多，此条仅作参考，整词记                                                               |
| **s** | 1. /s/ 词首：sun, see<br>2. /z/ 部分词中/词尾：music, rose, is——无可靠拼写规律（bus /s/ 对 rose /z/），整词记；复数和三单的词尾 -s 按清浊规律，见[[wiki/英语学习/02-声音与词汇#2 拼读、拼写与词尾读音\|声音与词汇]] |
| **x** | 1. /ks/ 默认：box, six, extra<br>2. /gz/ 词首 ex- 常读：exam, example, exact, exit<br>3. /z/ 词首罕见：xylophone                                                                                                    |

## 2 辅音组合

| 组合                | 发音与情况（多读以 1. 2. 3. 分行）                                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **ch**              | 1. /tʃ/ 多数：chair, teacher<br>2. /k/ 希腊源词：school, Christmas, chorus, chemist<br>3. /ʃ/ 法语源词：chef, machine, champagne                |
| **sh**              | /ʃ/：ship, fish, wash                                                                                                                           |
| **ph**              | /f/：phone, photo, elephant                                                                                                                     |
| **th**              | 1. /θ/ 多数实词：think, three, bath<br>2. /ð/ 功能词（the, this, they, then）与 -ther 词（mother, weather, other）——例外 author、Arthur，整词记 |
| **wh**              | 1. /w/ 多数：when, white, what<br>2. /h/ 仅 who、whose、whole 一组                                                                              |
| **ng**              | 1. /ŋ/ 词尾：sing, long<br>2. /ŋg/ 词中：finger, single——singer 读 /ŋ/ 对 finger 读 /ŋg/，无规律，整词记                                        |
| **ck**              | /k/：back, clock, black                                                                                                                         |
| **qu**              | /kw/：quick, queen, quiet——qu 后的元音按 w 规律走，见元音字母页                                                                                 |
| **kn**              | /n/（哑 k）：know, knife, knee                                                                                                                  |
| **wr**              | /r/（哑 w）：write, wrong                                                                                                                       |
| **gn**              | /n/（哑 g）：词首 gnaw；词中 sign（见元音组合页）；词尾 foreign                                                                                 |
| **mb（词尾）**      | /m/（哑 b）：climb, comb, lamb                                                                                                                  |
| **mn**              | 词尾 /m/（哑 n）：autumn, column；词首 /n/（哑 m）：mnemonic                                                                                    |
| **ps / pn（词首）** | /s/（哑 p）：psychology；pn：pneumonia                                                                                                          |
| **sc**              | 1. /sk/ 多数：scan, scarf<br>2. /s/ e/i 前（c 不发音，即 c 规则的延伸）：scene, science, scent                                                  |
| **sch**             | /sk/：school, scheme, scholar——schedule 英 /ʃ/、美 /sk/ 都常见                                                                                  |
| **dge**             | /dʒ/ 短元音后的词尾：badge, bridge, edge                                                                                                        |
| **tch**             | /tʃ/ 短元音后的词尾：catch, watch——但 rich、much、such 也常见，拼法不绝对，读音都是 /tʃ/                                                        |
| **gh**              | 1. 多数不发音（词中/词尾）：light, taught——详见元音组合页<br>2. /f/ 少数：laugh, enough, rough<br>3. /g/ 仅词首：ghost                          |
| **cc**              | 1. /k/ a/o/u/辅音前：occur, account<br>2. /ks/ e/i 前：accept, succeed, accident——例外 soccer，整词记                                           |
| **nk**              | /ŋk/：think, thank, pink                                                                                                                        |
| **rh**              | /r/（哑 h，词首）：rhyme, rhythm                                                                                                                |

## 3 低频参考与哑音词

- c 在 -cial/-cean 一类读 /ʃ/：special, ocean——与 -tion 同族，见元音组合页；
- cello /ˈtʃeloʊ/（意大利语借词，ch → /tʃ/）；
- 哑音字母词（整词记）：hour、honest（h 不发音）、island（s 不发音）、debt、doubt（b 不发音）、receipt（p 不发音）、Wednesday（d 不发音）、handsome（d 不发音）、listen、castle（t 不发音）、often（t 可发可不发）、sword（w 不发音）、subtle（b 不发音）；
- su 在 sugar、sure 读 /ʃ/，其余多 /s/（suit, super）——整词记；
- 词尾 -se 两读：/z/（nose, these, cheese）对 /s/（house, nurse, goose），无规律——lose /luːz/ 对 loose /luːs/ 整词记；ze、zz 一律 /z/（size, prize；buzz, pizza）；
- 词尾 -es 三种结局：嘶擦音后 /ɪz/（buses, boxes, washes——e 唯一发音的情况）；其余浊音后 /z/（goes, potatoes）；清辅音后 /s/（books）——机制是清浊同化，详见[[wiki/英语学习/02-声音与词汇#2 拼读、拼写与词尾读音\|声音与词汇]]；
- ss 读 /z/ 的小家族：scissors、dessert、possess——整词记；
- sph /sf/：sphere, sphinx；exhaust、exhibit 的 h 不发音，exhale 的 h 发音——整词记；
- colonel /ˈkɜːrnl/——l 读 /r/，英语拼写的著名惨案，整词记。

## 4 例外词卡

of（f 读 /v/，超高频孤例）、does /dʌz/ 与 says /sez/（连元音都变了）、get/give/girl/tiger/begin（g 例外组，读 /g/）、author/Arthur（-ther 读清音）、singer 对 finger、mouth（名词 /θ/，动词 /ð/）。
