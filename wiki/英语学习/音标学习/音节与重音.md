# 音节与重音

[[wiki/英语学习/音标学习/00-索引|返回音标学习索引]]

**做两件事：把词切成音节（决定用哪条读音规律），找重音（决定哪个音节读满、其余弱化）。** 必记的只有三句（§1），其余是查阅用的参考；重音最终以词典标注为准。

## 1 必记三句

1. **数音节＝数发响的元音**：哑音 e 不算，ai/ee 这类组合算一个；词中不发音的元音也不算（every、camera 只有发响的才算）。
2. **两个元音之间有两个辅音，从中间分**：let·ter、win·ter、hap·py——这就是"双写辅音锁短音"的原因。bl/cr/pl 这类辅音簇不拆，整体归后：se·cret。
3. **重音**：双音节名词、形容词多在第一（TA-ble）；带前缀的动词多在第二（be-GIN——其实是"前缀不重读"的推论）；本族短动词多在第一（LISten、STUdy、HAPpen）。前缀（un-/re-/im-/a-）一律不重读。

## 2 切分细则（查阅）

| 情况 | 怎么切 | 例词 |
| --- | --- | --- |
| 两个元音之间有两个辅音 | 从中间分 | let·ter, win·ter, hap·py |
| 辅音是 ch/sh/th/ph 等组合 | 不拆开，整个算一个辅音 | teach·er, moth·er |
| 辅音是 bl/cr/pl 等辅音簇 | 不拆，整体归后 | se·cret, a·pron |
| 两个元音之间只有一个辅音 | 认识的词用两试：先辅音归后读长音，读出来不像这个词就归前读短音；生词此处直接查词典 | mu·sic；riv·er、cam·el → camel |
| 词尾是辅音+le | 自成一个音节 | ta·ble, ap·ple, lit·tle |
| 有前缀后缀 | 前后缀天然是边界 | un·hap·py, talk·ing, work·er |

切分是手段不是目的：两种切法读音相同时（win·ter 和 wi·nter 里 i 都读 /ɪ/）不必纠结，真正要判断的只是"元音后面有没有辅音挡住"——挡住读短音，直通读长音。

## 3 重音规律（查阅）

- **双音节词**：名词、形容词约九成在第一音节；动词看来源——本族短动词在第一（LISten、STUdy、HAPpen、FINish、ANswer），带前缀的在第二（be-GIN、de-CIDE、for-GET，即前缀不重读）。名动对子：**RE**cord 唱片 / re-**CORD** 录制；**PRE**sent 礼物 / pre-**SENT** 呈现。
- **后缀定重音**：

| 类型 | 后缀与例词 |
| --- | --- |
| 吸走重音（重音在后缀上） | -ee（employ**EE**）、-eer（engin**EER**）、-ese（Japan**ESE**）、-oon（bal**LOON**）、-ette（cigar**ETTE**） |
| 拉到前一音节 | -tion/-sion（in**FOR**mation）、-ic（e**LEC**tric；例外：**CA**tholic、**LU**natic、**RHET**oric）、-ity（elec**TRI**city）、-ial（of**FI**cial） |
| 不影响重音 | -ful（**BEAU**tiful）、-ness（**HAP**piness）、-ly（**SLOW**ly）、-er（**TEACH**er；少数挪位：**PHO**tograph → pho**TO**grapher，整词记） |

- **三音节以上**：靠后缀定，拿不准查词典（ˈ 标在重读音节前）。不要用"倒数第三音节"之类的默认——banana、develop、deliver 都不在倒数第三。

## 4 多音节长词：拆积木

长的学术词＝词根＋前后缀，每块读音固定：

| 积木 | 读音 | 重音效果 |
| --- | --- | --- |
| -tion / -sion | /ʃən/；/ʒən、ʃən/ | 拉到前一音节 |
| -ic / -ical | /ɪk、ɪkl/ | 拉到前一音节 |
| -ity / -ily | /əti/ | 拉到前一音节 |
| -ial | /əl/ | 拉到前一音节 |
| -ful / -less | /fl、ləs/ | 不变 |
| -ness / -ly / -er | /nəs、li、ər/ | 不变 |
| un- / re- / im- / a- | /ʌn、rɪ、ɪm、ə/ | 前缀不重读 |

| 词 | 拆块 | 走法 |
| --- | --- | --- |
| information | in·for·MA·tion | -tion 前一音节 MA 重读 /meɪ/，其余弱化：/ˌɪnfərˈmeɪʃn/ |
| impossible | im·PO·ssi·ble | 前缀不重读，po 闭音节 /pɒs/：/ɪmˈpɒsəbl/ |
| electric / electricity | e·LEC·tric；e·lec·TRI·ci·ty | electric 靠 -ic（重 LEC），electricity 靠 -ity（重 TRI）——两个后缀两种机制，别混 |

边界三条（不用掌握，查词典即可）：次重音 ˌ（university 开头的 /juː/ 因此没弱化成 /ə/）；非重读音节读 /ɪ/ 还是 /ə/ 因词而异；词根跟着重音走（**PHO**tograph /ˈfoʊtəɡræf/ 到 pho**TOG**raphy /fəˈtɑːɡrəfi/ 里 photo 整块变音，整词记）。

## 5 怎么用

- **认识的词**：重音跟着单词一起记（听录音时留意），不现场推导。
- **生词**：单音节用字母规律；双音节加必记三句；长的先认后缀定重音、再拆块、非重读全部弱化。
- 读错或拿不准：查词典记一次。规律解决第一猜，词典是终审。
