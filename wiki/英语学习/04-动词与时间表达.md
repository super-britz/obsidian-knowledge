# 动词与时间表达

[[wiki/英语学习/00-索引|返回英语学习索引]] · [[wiki/英语学习/英语学习-知识地图#动词系统|返回对应地图]]

**看动词时连续问：发生什么、以哪个时间为参照、怎样看这件事、说话人什么态度、句子先谈谁。** 下面把这些问题分开，再组合。先学常用形式，进阶组合可先认读。

## 1 主要动词、系动词与助动词

- **主要动词**提供动作或状态的主要词汇意义，如 `read/like/know`。
- **系动词**把主语与对它的说明连接起来，如 `She is tired.`、`She seems tired.`（她累／似乎累）。`be/seem/become/look/sound` 等可有这种用法；系动词仍可作为句子的主要动词。
- **助动词**帮助构成时间、体、语态、疑问和否定等。常见 `be/have/do`，另有 `can/must/will` 等情态助动词。[动词组合][vp]

不要只凭拼写判断类别：

| 词 | 主要动词用法 | 助动词用法 |
| --- | --- | --- |
| `be` | `She is a teacher.` 她是老师 | `She is reading.` 她正在读；`is` 帮助构成进行 |
| `have` | `I have a bike.` 我有一辆车 | `I have finished.` 我已经完成；`have` 帮助构成完成 |
| `do` | `I do my homework.` 我做作业 | `Do you work here?` 你在这里工作吗；`do` 帮助构成疑问 |

**检查**：`She has a cat.` 的 `has` 表示“有”；`She has left.` 的 `has` 帮助构成完成，不能译成“拥有离开”。

## 2 动词的五种常见形式

| 名称 | `work` | `write` | 主要用在哪里 |
| --- | --- | --- | --- |
| 原形 | work | write | 词典词头；情态动词后；`to` 不定式中等 |
| 第三人称单数现在式 | works | writes | `she works` 这类一般现在肯定句 |
| 过去式 | worked | wrote | 一般过去，如 `she wrote` |
| 过去分词 | worked | written | 完成、被动及其他结构，如 `has written/was written` |
| -ing 形式 | working | writing | 进行及非谓语等，如 `is writing/enjoys writing` |

“过去式”和“过去分词”在规则动词中常同形，功能不同；`write/wrote/written` 更容易看清。过去分词的名称**不代表它自己能标出过去时间**。`be` 有 `am/is/are/was/were/been/being` 等形式，需要单独掌握。[动词组合与不规则动词][vp]

常见拼写：`study → studies/studied`，`play → plays/played`；以不发音 e 结尾常去 e 加 ing，如 `make → making`；部分重读短元音加单辅音结尾要双写，如 `stop → stopped/stopping`；`lie → lying`。这些是常见模式，例外查词典。

**检查**：`She has wrote a letter.` 应改成 `She has written a letter.`，因为完成结构需要过去分词。

## 3 时间、时态与体

**时间**是事情与过去、现在、将来的关系。**时态**是语法形式的一部分。**体**是怎样呈现事件的内部进展或它与参照时点的关系。[现在时体系][present] [过去时体系][past]

| 看事情的方式 | 常见构成 | 核心问题与例子 |
| --- | --- | --- |
| 一般形式 | 普通限定动词；未来等可另加助动词 | 当作事实、习惯或整体事件：`I read every day.` 我每天读书 |
| 进行体 | `be + -ing` | 从某个时间观察正在展开的过程：`I am reading.` 我正在读 |
| 完成体 | `have + 过去分词` | 回看参照时点之前，并把它与该时点联系：`I have read the book.` 我已读过这本书 |
| 完成进行 | `have + been + -ing` | 回看此前持续的过程：`I have been reading for an hour.` 我已经读了一小时 |

完成不等于“事情一定结束”。`I have lived here for five years.` 可表示现在仍住这里。进行不等于“永远短暂”；是否仍持续、是否完成，需要动词本身和语境一起判断。[现在完成][perfect]

中文教学常把“时间 × 体”的组合称为若干种“时态”；按动词屈折形态区分的参考语法则常说英语有现在、过去两种时态，将来另用结构表达。名称可以不同，重点是读懂具体组合，不能只背数字。

**检查**：`I read the book yesterday.` 把事件放在已结束的过去时间；`I have read the book.` 说明截至现在的经历或相关情况，关注点不同。

## 4 原书的八个入门锚点

原书选取下列八项；这是教学选取，不是所有组合。[原书定位见知识地图](英语学习-知识地图.md#动词系统)。下表解释依语言参考重新组织，例句自拟。

| 名称 | 常见构成 | 例句与实际意思 |
| --- | --- | --- |
| 一般现在 | 原形／第三人称单数；`be` 另变 | `She reads every night.` 她每晚读书；表达习惯，不是断言此刻正在读 |
| 现在进行 | `am/is/are + -ing` | `She is reading now.` 她现在正在读；也可表达已安排的将来活动 |
| 一般过去 | 过去式 | `She read it yesterday.` 她昨天读了它；此处 `read` 读 /red/ |
| 一般将来 | 常见 `will + 原形` | `I will call you tomorrow.` 我明天给你打电话；将来还有其他表达 |
| 现在完成 | `have/has + 过去分词` | `She has read this book.` 她已读过这本书；把此前经历与现在联系 |
| 过去进行 | `was/were + -ing` | `She was reading at eight.` 她八点时正在读；观察过去某时的过程 |
| 过去完成 | `had + 过去分词` | `She had left when I arrived.` 我到达时她已经走了；离开早于到达这个过去参照点 |
| 过去将来 | 常见 `would + 原形` 或 `was/were going to` | `She said she would call.` 她说她会打电话；从当时往后看 |

事实与习惯、正在展开的过程、过去整体事件、相对于某时点的先后，必须结合上下文判断。`yesterday/now/since` 是线索，不是脱离结构就能选唯一答案的开关。[现在][present] [过去][past] [将来][future]

### 常见误区

- 一般现在肯定句 `She likes tea.`，变否定为 `She doesn't like tea.`；不要保留第二个 s。
- 许多状态用法通常不用进行：`I know the answer.`，通常不说 `I am knowing the answer.`。同一个词可因用法改变：`I think …` 表观点，`I am thinking about …` 表正在考虑。
- 常规用法里，`yesterday/last year` 等明确结束的过去时间常配一般过去，不说 `I have seen him yesterday.`。
- 现在完成的 `since Monday` 给起点，`for two days` 给时长；它们也可出现在其他时间结构中，并非现在完成专用。

## 5 其余组合与将来表达

### 补齐常见组合的范围

以下八项连同上一节八项，覆盖传统教学常提的十六种时间／体组合。**认得全表不等于初学就要熟练使用全部组合**。它们由同一套助动词机制构成，不是十六套互不相干的规则。[动词组合][vp] [现在][present] [过去][past] [将来][future]

| 组合 | 形式与自拟例句 | 意思 |
| --- | --- | --- |
| 现在完成进行 | `have/has been doing`：`I have been studying for an hour.` | 一直到现在已学了一小时，突出过程 |
| 过去完成进行 | `had been doing`：`I had been studying for an hour when she called.` | 她打电话那个过去时点之前，我已学了一小时 |
| 将来进行 | `will be doing`：`I will be studying at eight.` | 预计八点时处在学习过程中 |
| 将来完成 | `will have done`：`I will have finished by Friday.` | 到周五这个将来参照点，预计已完成 |
| 将来完成进行 | `will have been doing`：`By June, I will have been studying English for a year.` | 到六月，学习过程将持续满一年 |
| 过去将来进行 | `would be doing`：`She said she would be studying at eight.` | 她从当时预计，八点会在学习 |
| 过去将来完成 | `would have done`：`She said she would have finished by Friday.` | 她从当时预计，到周五会完成 |
| 过去将来完成进行 | `would have been doing`：`She said that by June she would have been studying English for a year.` | 她从当时预计，到六月学习将持续满一年 |

最后几项先会拆解即可。`would have done` 还常用于反事实条件等；不能看到形式就自动译成“过去将来”，见[[wiki/英语学习/05-从句与句式#8 条件与虚拟表达|条件与虚拟]]。

### 将来不只用 will

| 表达方式 | 常见用途 | 例句 |
| --- | --- | --- |
| `will + 原形` | 预测、承诺、当下决定等 | `I'll help you.` 我来帮你 |
| `be going to + 原形` | 已有打算，或基于当前迹象预测 | `I'm going to study tonight.` 我今晚打算学习 |
| 现在进行 | 已安排的活动 | `I'm meeting Mei tomorrow.` 我明天要见 Mei |
| 一般现在 | 时刻表或固定安排 | `The train leaves at six.` 火车六点出发 |

这些用途可重叠，不是仅靠一个中文“将”就能决定。表示未来的时间或条件从句常用现在形式：`I'll call when I arrive.`；`If it rains, we'll stay home.`。但表示“是否”的宾语从句可以说 `I don't know if it will rain.`。[将来表达][future]

**检查**：同样谈明天，你能分清“已有约定”“时刻表”“当下答应”三种语境，并选出一个合适表达。

## 6 情态：说话人对事情的判断或要求

核心情态动词通常后接原形，不随第三人称加 s：`She can swim.`，不说 `She cans swim.`。它们既可谈能力、许可、义务，也可表示推测；同一个词不只有一个中文意思。[情态动词][modals]

| 用途 | 常见形式 | 例子与边界 |
| --- | --- | --- |
| 能力 | `can/could/be able to` | `I can swim.` 我会游泳；`could` 可谈过去能力，也可有其他用法 |
| 许可与请求 | `can/could/may` | `Could you help me?` 能帮我吗；此处 `could` 不表示过去 |
| 可能与推测 | `may/might/could/must/can't` | `She might be home.` 她可能在家；`She must be home.` 根据线索作较强判断；不是可验证的固定概率表 |
| 必要与义务 | `must/have to/need to` | `You have to show your ticket.` 你必须出示票；`have to` 等形式规则与核心情态不同 |
| 建议 | `should/ought to` | `You should rest.` 你应该休息；不等同于命令 |
| 意愿、预测或习惯等 | `will/would` | `Would you like some tea?` 想喝茶吗；不必表示过去或假设 |

另需认出 `shall`：`Shall we start?` 可用于提出共同开始的建议；它也出现在较正式的用法中。`ought to`、`have to`、`be able to` 等与核心情态形式不完全相同，要把整个表达及其变化一起学。

**必须分清否定**：`You mustn't go.` 是“你不准去”；`You don't have to go.` 是“你不必去”。`may not` 在语境中可能表示“不许可”或“可能不”，要结合说话意图。

**进阶：对过去作判断**。`must have left`（推测已经离开），`might have left`（可能已经离开），`should have called`（在常见语境里表示本该打电话，通常暗示未打）。这里 `have + 过去分词` 将判断指向此前，并非所有组合都表达同一种事实状态。

**检查**：把“不用今天完成”说成 `You don't have to finish today.`；若说成 `mustn't`，意思就变为禁止。

## 7 主动与被动

主动与被动可以从不同对象展开同一件事：

- `Mei opened the door.`：从 Mei 说起。
- `The door was opened by Mei.`：从门说起。

两句的事件角色没有因此互换：开门的人都是 Mei，门都是被打开的对象。变的是语法安排和信息组织；主动句也可以靠重音等突出门，因此“焦点”不是只由语态决定。[被动与信息组织][passive]

常见被动为 **`be + 过去分词`**，时间等信息由整个组合承载：[主动与被动][voice]

| 形式 | 例句与意思 |
| --- | --- |
| 一般现在被动 | `The room is cleaned every day.` 房间每天被打扫 |
| 过去被动 | `The room was cleaned yesterday.` 昨天打扫过房间 |
| 进行被动 | `The room is being cleaned.` 房间正在被打扫 |
| 完成被动 | `The room has been cleaned.` 房间已经打扫过 |
| 情态被动 | `The room must be cleaned.` 房间必须打扫 |

不知道、不重要或不想强调动作发出者时，可以省略 `by …`。并非任何动词都能机械变被动：通常不能把不及物的 `arrive` 写成 `was arrived`。系表结构也不等于被动。

`The door is closed.` 可描述关着的状态；是否强调关闭事件须看语境。遇到 `be + 过去分词外形`，不要不加判断地贴被动标签。还会见到 `get + 过去分词`，如 `got hurt`；先认识这种常见补充形式即可。[主动与被动][voice]

**检查**：把“有人修好了我的自行车”改成先谈自行车：`My bike has been repaired.`；能说明修车的人不必出现在句子里。

## 8 动词组合怎样拆

在常见陈述动词链中，可以按这个顺序识别：**情态 → 完成 have → 进行 be → 被动 be → 主要动词**，需要什么才出现什么。每一层约束后面紧接的形式：情态后用原形，完成 have 后用过去分词，进行 be 后用 -ing，被动 be 后用过去分词。[动词组合][vp]

| 组合 | 拆解 | 读出的信息 |
| --- | --- | --- |
| `has been fixed` | `has` + `been`（be 的过去分词）+ `fixed` | 现在完成加被动，已经被修好 |
| `is being fixed` | `is` + `being`（be 的 -ing）+ `fixed` | 进行加被动，正在被修 |
| `may have been fixed` | `may` + `have` + `been` + `fixed` | 对此前修复作可能性判断，加被动 |
| `has been working` | `has` + `been` + `working` | 完成进行，突出工作持续的过程；没有被动 |

不要把所有理论上可堆叠的层都主动用上；少见的冗长组合可先拆读，表达时可选择更清楚的句子。

**综合自测**：`The bike may have been repaired.` 能确定已修好吗？——不能；`may` 保留可能性，`have` 把判断指向此前，`been repaired` 表被动。翻成“自行车已经修好了”会丢失不确定性。
