# AI Agent 架构学习索引

> [!abstract] 本专题不按原书 45 个章节逐一摘录，而是围绕一个根问题整理：如何把只能基于当前上下文生成 Token 的 LLM，工程化为能在真实环境中持续、受限、可恢复地完成任务的系统。

1. [[wiki/AI Agent 架构/01：Agent 的本质|Agent 的本质]]：第 1 章的核心结论——什么条件下，模型的“生成回答”才升级为系统的“受控行动”。
2. [[wiki/AI Agent 架构/02：ReAct 循环|ReAct 循环]]：第 2 章的运行机制——怎样通过“推理 → 行动 → 观察”用新证据修正下一步。
3. [[wiki/AI Agent 架构/03：工具与行动边界|工具与行动边界]]：第 3 章的能力边界——模型怎样提出调用意图，程序怎样校验、执行、限制并返回事实回执。
4. [[wiki/AI Agent 架构/04：MCP 工具互操作|MCP 工具互操作]]：第 4 章的复用边界——不同 Client 怎样发现、协商并受控使用不同 Server 的能力。
5. [[wiki/AI Agent 架构/05：Skills：任务能力封装|Skills：任务能力封装]]：第 5 章的任务边界——怎样按需装载角色、工作流知识、最小工具集与资源约束。
6. [[wiki/AI Agent 架构/06：Hooks 与事件控制|Hooks 与事件控制]]：第 6 章的运行时控制面——怎样在生命周期中观察、暂停、审批、恢复和扩展执行。
7. [[wiki/AI Agent 架构/07：上下文工程|上下文工程]]：第 7 章的决策工作集——怎样在有限窗口内选择、外置、压缩与隔离信息，使每一轮都看到完成当前步骤所需的最小高信号证据。
8. [[wiki/AI Agent 架构/08：记忆架构|记忆架构]]：第 8 章的跨时经验系统——怎样定义信息的写入、范围、召回、验证与遗忘，使历史能帮助当前任务而不污染事实与权限边界。
9. [[wiki/AI Agent 架构/09：多轮对话与会话状态|多轮对话与会话状态]]：第 9 章的连续交互边界——怎样以 Session 绑定身份、状态、历史、隐私与故障恢复，而不把聊天记录误当作系统状态。
10. [[wiki/AI Agent 架构/10：任务规划与控制|任务规划与控制]]：第 10 章的复杂任务控制——怎样将目标转成有产物、依赖、边界和验收的子任务，并依据执行事实和预算持续修订或停止。

12. [[wiki/AI Agent 架构/12：结构化推导与证据验证|结构化推导与证据验证]]：第 12 章的可检查推导——怎样把多步问题外化为中间论断与结论，并以外部证据而非解释文本完成验证。

## 先抓住这条因果链

```text
目标与环境
→ 组织当前状态和上下文
→ LLM 提议下一步
→ 在权限、预算与审批边界内执行
→ 观察真实结果并更新状态
→ 决定继续、重试、转交或停止
```

LLM 提供候选决策；运行时负责执行、观察、限制和验证。后续所有主题——ReAct、工具、记忆、规划、多 Agent、可观测性与治理——都是在补强这条闭环的某一环。

## 怎样使用这套笔记

每读一章，只回答五个问题，而不复述章节：

1. **能力缺口：** 原有系统缺少什么，因而会怎样失败？
2. **机制：** 新增了什么状态、循环、接口或约束？
3. **代价：** 成本、延迟、复杂度、权限或副作用增加了什么？
4. **边界：** 缺少它会怎样坏，滥用它又会怎样坏？
5. **决策：** 什么条件下采用，如何验证，失败时怎样回退？

正式概念页统一使用“机制 → 约束与失败表现 → 工程决策”的结构。学习方法不单独占主线文件；只有形成可复用的模式或项目决策时，才补充模式卡或 ADR。
