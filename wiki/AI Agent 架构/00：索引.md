# AI Agent 架构学习索引

> [!abstract] 本专题不按原书 45 个章节逐一摘录，而是围绕一个根问题整理：如何把只能基于当前上下文生成 Token 的 LLM，工程化为能在真实环境中持续、受限、可恢复地完成任务的系统。

## 先抓住这条因果链

```text
目标与环境
→ 组织当前状态和上下文
→ LLM 提议下一步
→ 在权限、预算与审批边界内执行
→ 观察真实结果并更新状态
→ 决定继续、重试、转交或停止
```

LLM 提供候选决策；运行时负责执行、观察、限制和验证。后续所有主题——ReAct、工具、记忆、规划、多 Agent、可观测性与治理——都是在补强这条闭环的某一环。

## 怎样使用这套笔记

每读一章，只回答五个问题，而不复述章节：

1. **能力缺口：** 原有系统缺少什么，因而会怎样失败？
2. **机制：** 新增了什么状态、循环、接口或约束？
3. **代价：** 成本、延迟、复杂度、权限或副作用增加了什么？
4. **边界：** 缺少它会怎样坏，滥用它又会怎样坏？
5. **决策：** 什么条件下采用，如何验证，失败时怎样回退？

正式概念页统一使用“机制 → 约束与失败表现 → 工程决策”的结构。学习方法不单独占主线文件；只有形成可复用的模式或项目决策时，才补充模式卡或 ADR。
