# AI Agent 架构

[[wiki/00-索引|返回知识库首页]]

本专题回答：怎样让 LLM 通过工具和状态，在权限、成本与时间约束内完成可验证的任务。

## 先从这里开始

- **第一次学：** 按下面的基础路径读；[[wiki/AI Agent 架构/00-导读——从 Agent 闭环到生产系统|学习方法与验收]]说明每篇需要掌握什么。
- **带着问题来：** 从下面的「按问题查」进入对应机制。
- **正在选方案：** 先看[[wiki/AI Agent 架构/附录-模式选择与渐进复杂度|模式选择]]；术语容易混淆时查[[wiki/AI Agent 架构/附录-术语与系统边界|术语与系统边界]]。

**基础路径：** [[wiki/AI Agent 架构/01-Agent 的本质|01 Agent 本质]] → [[wiki/AI Agent 架构/02-ReAct 循环|02 行动与观察]] → [[wiki/AI Agent 架构/03-工具与行动边界|03 工具边界]] → [[wiki/AI Agent 架构/07-上下文工程|07 上下文]] → [[wiki/AI Agent 架构/10-任务规划与控制|10 任务控制]]。

先学会定义目标、选择工具、读取结果和判断停止，再按实际瓶颈扩展。
