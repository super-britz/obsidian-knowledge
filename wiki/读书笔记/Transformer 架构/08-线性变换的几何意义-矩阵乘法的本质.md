# 第 8 章：线性变换的几何意义 - 矩阵乘法的本质

> [!abstract] 一句话理解
> **矩阵乘法既能把向量变成新的表示，也能批量计算向量之间的匹配分数；Attention 使用它来计算 Q 和 K 的匹配程度。**

## 核心结论

- 向量是一排数字，矩阵是多排数字组成的表格。
- 矩阵乘法的维度规则是：`[A, B] @ [B, C] = [A, C]`。
- 点积就是“对应位置相乘，再求和”。
- 矩阵乘法可以批量计算许多向量之间的点积。
- Attention 用 `QKᵀ` 得到 Query 和 Key 的匹配分数，再经过缩放、Mask 和 Softmax 变成权重。

## 主流程：矩阵乘法如何进入 Attention

```text
Token 向量
  ↓ 线性变换
Q、K、V
  ↓
QKᵀ：批量计算 Q 和 K 的匹配分数
  ↓
除以 √d_k：控制分数尺度
  ↓
Mask：屏蔽不允许看到的位置
  ↓
Softmax：分数变成权重
  ↓
用权重组合 V
```

本章先理解 `QKᵀ` 为什么能得到匹配分数；Q、K、V 的具体分工放到下一章展开。

## 核心概念

### 1. 三种数字结构

- **Scalar（标量）**：一个数字；
- **Vector（向量）**：一排有顺序的数字；
- **Matrix（矩阵）**：多排数字组成的二维表格。

在 Transformer 中，一个 Token 通常用向量表示，一批 Token 可以组成矩阵，模型的权重也通常是矩阵。

### 2. 矩阵乘法的维度规则

```text
[A, B] @ [B, C] = [A, C]
```

中间的 `B` 必须相同，结果保留两边的外部维度 `A` 和 `C`。

这条规则用来判断：

- 两个矩阵能不能相乘；
- 相乘后结果是什么形状；
- 向量经过变换后会变成多宽。

### 3. 点积是什么

```text
A · B = a₁b₁ + a₂b₂ + ... + aₙbₙ
```

点积就是对应位置相乘，再把结果相加。它会得到一个数字，可以作为两个向量的匹配分数。

如果把很多向量排成矩阵，一次矩阵乘法就能同时算出大量点积：

```text
Q [seq_len, d_k] @ Kᵀ [d_k, seq_len]
      ↓
匹配分数 [seq_len, seq_len]
```

结果中的每个位置，都代表一个 Query 和一个 Key 的分数。

### 4. 矩阵乘法也是线性变换

同一个矩阵乘法可以从两个角度理解：

- **计算角度**：矩阵相乘、批量计算点积；
- **表示角度**：用一个矩阵把向量变成新的表示。

Transformer 中很多地方都在做这种变换：

- Attention 的 Q、K、V 投影；
- FFN 的扩宽与缩回；
- LM Head 映射到词表分数。

### 5. 点积的几何意义

点积同时受到两件事影响：

- 两个向量的方向是否接近；
- 两个向量的长度有多大。

方向接近且长度较大时，点积通常更大；方向相反时，点积可能为负。

因此，点积可以理解为一种“方向和长度共同参与的匹配分数”。它**不等于余弦相似度**，因为余弦相似度还会除以两个向量的长度，只保留方向因素。

“投影”是理解点积的另一种直觉：点积反映一个向量在另一个方向上有多少成分。

### 6. 为什么这对 Attention 重要

Attention 需要判断：

> 当前 Query 应该关注哪些 Key？

`QKᵀ` 会一次算出所有 Query-Key 的匹配分数。然后：

```text
匹配分数 → 缩放 → Mask → Softmax → 注意力权重
```

所以，矩阵乘法是 Attention 计算匹配分数的工具，Softmax 再把分数变成权重。
