# 第 2 章：大模型的本质

> [!abstract] 一句话理解
> 大模型通过预测下一个 Token 生成内容；训练得到参数，推理代码使用参数，二者共同构成模型本体的基本抽象。

## 核心结论

- GPT 通过预测下一个 Token 学习语言规律，并采用自回归方式逐个生成内容。
- 参数是训练得到的大量数字，分布式地编码语言模式，不是一条条可以直接查询的知识。
- 训练负责更新参数，推理负责使用固定参数生成内容。
- “参数文件 + 推理代码”是理解模型本体的简化抽象，真实系统还包括 Tokenizer、配置和服务组件。

## 主流程：GPT 如何生成内容

```text
已有上下文
  ↓
计算下一个 Token 的概率分布
  ↓
选择或采样一个 Token
  ↓
追加到上下文
  ↓
重复，直到结束
```

这就是 **Autoregressive Generation（自回归生成）**：每一步都根据已经出现的内容预测下一步。

## 核心概念

### 1. 下一个 Token 预测

语言模型不是一次性生成完整答案，而是反复完成同一个任务：

```text
P(下一个 Token | 已有上下文)
```

Token 是模型的基本生成单位，不固定等于一个字或一个单词。

### 2. 训练与推理

| 对比项 | Training（训练） | Inference（推理） |
| --- | --- | --- |
| 目标 | 从数据中学习参数 | 使用参数生成内容 |
| 参数状态 | 持续更新 | 通常保持不变 |
| 输入 | 大规模训练数据 | 用户输入和已有上下文 |
| 结果 | 参数文件 | Token 概率与生成结果 |

可以概括为：

```text
训练：数据 → 预测误差 → 调整参数 → 参数文件
推理：输入 + 参数 → 概率分布 → 逐个生成 Token
```

### 3. 参数是什么

参数是模型训练得到的大量数字，可以理解为模型对语言规律和数据模式的分布式记忆。

它们不是数据库中的事实记录，通常不能从某一个参数直接读取某条知识。

### 4. “大模型就是两个文件”

这是对模型本体的简化抽象：

| 组成 | 作用 |
| --- | --- |
| Parameter File（参数文件） | 保存训练得到的数字 |
| Inference Code（推理代码） | 定义如何加载参数并执行计算 |

真实部署通常还需要：

- Tokenizer（分词器）；
- Model Configuration（模型配置）；
- 推理框架与服务代码；
- 安全、监控和业务系统。

### 5. 两个延伸概念

- **KV Cache（键值缓存）**：保存已经计算过的 Key 和 Value，减少生成过程中的重复计算。
- **MoE（Mixture of Experts，混合专家）**：每个 Token 只激活部分专家网络，在较大总参数量下控制实际计算量。

| 英文 / 缩写 | 中文 | 含义 |
| --- | --- | --- |
| Autoregressive Generation | 自回归生成 | 根据已有序列逐步预测后续 Token |
| Token | 文本 / 生成单元 | 模型处理和生成的基本单位 |
| Parameter | 参数 | 训练得到的模型数字 |
| Training | 训练 | 根据数据更新参数 |
