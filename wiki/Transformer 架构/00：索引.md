## 核心主线

按下面顺序阅读，就能建立完整生成链：

1. [[01-03：LLM 与 Transformer|LLM 与 Transformer]]：模型为什么不断预测下一个 Token。
2. [[04：Tokenization|Tokenization]]：文字怎样变成模型能处理的编号。
3. [[05：位置编码|位置编码]]：模型怎样知道 Token 的顺序。
4. [[06：LayerNorm 与 Softmax|LayerNorm 与 Softmax]]：内部数字怎样保持稳定，候选分数怎样变成概率。
5. [[07：FFN|FFN]]：Token 取得上下文后，怎样加工自己的表示。
6. [[08：线性变换|线性变换]]：模型怎样按照学到的权重重新组合数字。
7. [[09-12：Attention|Attention]]：当前 Token 怎样从前文取得相关信息。
8. [[13-15：Transformer Block 与前向传播|Transformer Block 与前向传播]]：这些组件怎样组成完整模型。
9. [[16-17：训练、推理与参数更新|训练与推理]]：训练怎样改参数，推理怎样逐 Token 生成。
10. [[28：Prompt 工程|Prompt 工程]]：应用怎样组织一次模型调用。
11. [[附录：解码与采样策略|解码与采样策略]]：模型怎样选出下一个 Token。
