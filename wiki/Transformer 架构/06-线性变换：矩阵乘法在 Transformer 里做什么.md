# 线性变换：矩阵乘法在 Transformer 里做什么

> [!abstract] 矩阵乘法在 Transformer 里有两个关键用途：一是用权重矩阵把向量变成新的表示，二是批量计算很多向量之间的点积。后面的 Q、K、V、Attention 和 FFN 都依赖这两件事。

## 先看流程

```text
Token 向量矩阵 [序列长度, d_model]
× 权重矩阵 [d_model, 新维度]
= 新向量矩阵 [序列长度, 新维度]
```

中间维度必须相同：

```text
[A, B] × [B, C] = [A, C]
```

可以把它理解为：权重矩阵像一套可训练的“变换规则”，把原来的数字表示换成另一种更适合当前任务的表示。

> [!example] 先只看两个数字
> 假设一个向量是 `[2, 1]`，权重矩阵是 `[[1, 4], [2, 3]]`。相乘得到 `[4, 11]`：第一个输出是 `2×1 + 1×2`，第二个输出是 `2×4 + 1×3`。也就是说，**每个输出数字都是把原输入的数字按不同权重重新混合出来的结果**。这就是这里说的“线性变换”；不需要先把它想成复杂几何。

## 关键理解

- **向量是一组有序数字，矩阵是数字表格。** 一个 Token 的向量、整段文本的向量矩阵、模型的权重矩阵，都是 Transformer 里的常见对象。
- **矩阵乘法可以做线性变换。** 同一个输入向量乘不同权重矩阵，可以得到 Q、K、V，或在 FFN 中扩宽、缩回不同维度。
- **矩阵乘法也可以批量算点积。** `QKᵀ` 一次得到所有 Query 和 Key 的匹配分数，而不必一个个手算。
- **点积不是余弦相似度。** 点积同时受向量方向和长度影响；只有额外除以两个向量长度，才是余弦相似度。Attention 用的是学习出的 Q、K 点积匹配分数，不是普通语义相似度搜索。

> [!tip] 先只记住这三句
> 1. **线性变换 = 按权重重新混合输入数字，得到新的数字表示。**
> 2. **矩阵乘法 = 一次性对很多向量做这种重新混合。**
> 3. **Q、K、V = 同一个 Token 向量经过三套不同权重变换后的三个版本。**

## 做项目时记住

1. **看 shape 是理解模型代码最快的方法。** 每次矩阵乘法先确认输入最后一维和权重第一维是否相同。
2. **把 Q、K、V 理解成同一输入的三种“任务视角”。** 它们不是天生固定含义，而是由不同可训练投影矩阵得到。
3. **不必手算大矩阵。** 只需能读懂 `输入 shape → 权重 shape → 输出 shape`，并知道 `QKᵀ` 为什么会产生位置对位置的分数表。

## 别误解

- **“矩阵乘法只是很多数字相乘。”** 它既是数值计算，也是模型学习如何改变表示、比较表示的主要方式。
- **“点积大就表示两个词语义相同。”** 在 Attention 中，Q、K 是训练出来的投影；高分表示当前任务下更匹配，不是通用词典意义上的相似。
- **“矩阵乘法和 Softmax 是同一类操作。”** 前者产生变换或分数，后者把分数转换成概率权重；两者在 Attention 中顺序配合。
