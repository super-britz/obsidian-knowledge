# 第 32 章：状态空间模型与混合架构——用固定状态压缩历史

> [!abstract] SSM 用递归状态把历史压缩为固定维度表示，换取随序列长度线性增长的扫描和不随上下文长度增长的 Decode 状态；Mamba 让写入、读取和时间尺度依赖当前输入，改善静态 SSM 的内容选择能力。代价是历史访问被压缩，精确检索和 In-Context Learning 未必胜过 Attention，因此混合架构保留少量 Attention 作为显式访问通道。

> [!info] 阅读粒度
> 本页把 Attention、SSM、Mamba、Mamba-2 和 Hybrid 放进同一张“历史怎样被保存与访问”的契约中，因此标为“深入机制”；快速阅读时先看访问语义、Selective Scan、资源账和选型矩阵。

## Attention 与 SSM 保存历史的方式不同

Full Causal Attention 保留每个历史 Token 的 K/V，新 Token 可以按内容直接读取任意历史位置；SSM 则在每一步把旧状态和当前输入合并成新状态：

```text
Attention：历史 Token → 全部 K/V → 当前 Query 直接加权读取
SSM：       h_(t-1) + x_t → h_t → y_t
```

Attention 的分数计算包含长度为 L 的成对关系，算术量随 `L²` 增长。Flash Attention 通过 Tiling 避免把完整 `L×L` 分数矩阵写回 HBM，显著降低临时内存和 IO，但 Dense Attention 的成对算术仍然存在。自回归 Decode 有 KV Cache 后，每个新 Token 的 Attention 计算和缓存读取随历史长度线性增长，KV 状态也随 L 增长。

SSM 的递归推理每步只读固定维度状态，状态大小不随 L 增长，但这意味着历史必须被压缩。它不是“无限无损记忆”：若任务要求逐字找回任意早期事实，有限状态可能成为瓶颈。

## 从连续状态方程到离散递归

线性连续时间 SSM 常写为：

```text
h'(t) = A h(t) + B x(t)
y(t)  = C h(t) + D x(t)
```

选择步长 `Δ` 并离散化后得到：

```text
h_t = Ā h_(t-1) + B̄ x_t
y_t = C h_t + D x_t
```

`A` 控制状态怎样延续或衰减，`B` 控制输入怎样写入，`C` 控制怎样读出。对线性时不变系统，同一组参数作用于所有位置，递归形式适合流式推理，也可转成卷积形式并行训练。S4 通过结构化状态矩阵和高效核计算，让这条路线能处理长依赖。

这里的“递归状态 O(1)”只针对**相对于上下文长度的 Decode 状态**。训练仍需处理整个序列，通常保存随长度增长的激活；模型参数、Batch 和输出也不会消失。

## Mamba 的 Selective SSM

静态 SSM 对不同 Token 使用相同的写入和读取规则，难以根据内容选择保留什么。Mamba 让以下参数由当前输入生成：

```text
Δ_t = fΔ(x_t)
B_t = fB(x_t)
C_t = fC(x_t)
```

其中结构化 `A` 保持为模型参数；输入相关的 `Δ_t` 改变状态演化时间尺度，`B_t` 决定怎样写入，`C_t` 决定怎样读出。选择性不是 Attention 权重的同义词：Attention 保留历史位置并直接匹配，Mamba 仍通过递归状态传递，只是状态更新规则随内容变化。

输入相关参数破坏了线性时不变 SSM 的全局卷积形式。Mamba 因此使用硬件感知 Selective Scan：把递归的结合结构组织成并行扫描，并融合离散化、状态更新和门控，减少显存往返。算法复杂度随长度线性增长，但真实速度取决于 Kernel、状态维度、精度、Batch 和序列长度；论文中的吞吐倍数不是跨硬件常数。

## Mamba-2 与 State Space Duality

Mamba-2 从结构化半可分矩阵（Semiseparable Matrix）视角连接 SSM 与一类掩码 Attention：递归状态可以展开成一个具有特殊结构的序列变换矩阵，而某些线性 / 结构化 Attention 也可写成相近形式。

State Space Duality 的价值是允许在递归算法和矩阵乘法算法之间选择，并让 Mamba-2 更好利用 Tensor Core。它揭示的是一组数学联系，不意味着标准 Softmax Attention 和任意 SSM 完全等价，也不证明 Mamba 在所有语言任务上取代 Transformer。

## 为什么混合架构保留 Attention

固定状态擅长用稳定成本汇总长历史，Attention 擅长按内容直接读取具体位置。Hybrid 将两者按层或模块组合：

```text
多数 Mamba / Recurrent 层：持续压缩和更新历史状态
少量 Attention 层：重新建立 Token 间显式内容访问
可选 MoE：增加参数容量，不改变上述历史访问语义
```

Jamba 是公开实例之一：交替使用 Transformer 与 Mamba 层，并在部分层加入 MoE。其具体模型报告 52B 总参数、12B 激活参数，并展示最高 256K Token 的长上下文评测。这里三种机制分别解决不同问题：Mamba 控制序列状态成本，Attention 提供显式访问，MoE 扩展条件参数容量。

混合比例没有普遍最优值。Attention 太少可能损害精确召回与 In-Context Learning，太多则重新增加 KV Cache 和长序列计算；MoE 还会引入 [[30：Mixture of Experts|专家通信与负载问题]]。

## 资源与能力账本

| 维度 | Full Attention | Selective SSM | Hybrid |
| --- | --- | --- | --- |
| 历史表示 | 保存逐 Token K/V | 压缩为固定维状态 | 两种表示并存 |
| Prefill 序列算术 | Attention 部分二次 | 扫描部分线性 | 取决于 Attention 比例 |
| Decode 状态 | KV Cache 随长度增长 | 每层状态相对 L 固定 | KV + SSM State |
| 精确历史访问 | 强，可直接匹配位置 | 受状态压缩限制 | 用少量 Attention 补充 |
| 训练并行 | 成熟矩阵计算 | 需要专用 Scan / Kernel | 工具链更复杂 |
| 生态与部署 | 最成熟 | 后端支持不一 | 组件和并行策略更多 |

不能只按渐近复杂度选架构。短序列下，成熟 Attention Kernel 可能更快；长序列下，输入是否真的需要全量精确访问、模型是否经过对应长度训练、Batch 和硬件能否发挥 Scan，都会改变结果。

## 失败表现与验证

- **困惑度正常但检索失败：** 状态能支持局部预测，却压缩掉了稀有早期事实；做距离扫描、Key-Value Recall 和多干扰项测试。
- **长序列吞吐好但任务质量差：** 线性处理不等于可靠利用；同时测真实长文问答、跨段组合和位置偏差。
- **论文速度无法复现：** 检查是否使用官方融合 Kernel、相同精度、Warm-up、Batch、长度和计时边界。
- **流式状态重载后输出变化：** State 是运行时契约；验证 Chunked 与整段 Prefill、保存—恢复和不同分块边界的一致性。
- **Hybrid 显存仍随长度增长：** 剩余 Attention 层仍维护 KV Cache；按层拆分 KV 与 SSM State，不能只报总量。

最低验证矩阵应包含长度 × 关键信息位置 × 干扰数量 × 任务类型。性能上分开记录 Prefill、单步 Decode、吞吐、峰值内存和状态大小；质量上同时测语言建模、精确召回、In-Context Learning、推理与目标业务任务。

## 工程决策

```text
任务需要频繁、精确访问任意历史位置？
├─ 是：优先 Full / Sparse Attention，或保留足够 Attention 的 Hybrid
└─ 否：是否以流式、超长序列、固定状态为主要约束？
   ├─ 是：评估 SSM / Mamba
   └─ 否：成熟 Dense Transformer 通常成本更低
```

不要用固定的 4K、8K 阈值选架构。真正的分界来自目标硬件、并发、输入分布、访问模式和质量要求。已有 Transformer Checkpoint、工具链和量化生态也是迁移成本；新骨干通常需要重新预训练或使用专门转换方案，不能直接替换 Block 就继承能力。

## 别误解

- **“Flash Attention 已把 Attention 变成 O(L)。”** 它降低显存 IO 和物化内存，没有取消 Dense 成对计算。
- **“SSM 用 O(1) 内存记住无限历史。”** 固定状态压缩历史，容量和可恢复信息有限；训练内存也不恒定。
- **“Mamba 就是线性 Attention。”** 二者可在更一般框架中联系，但 Mamba 的执行核心是输入选择性状态递推。
- **“Mamba 的所有 A、B、C 都依赖输入。”** 原始 Selective SSM 主要让 `Δ`、`B`、`C` 输入相关，结构化 `A` 保持参数化。
- **“线性复杂度保证任何长度都更快。”** Kernel、Batch、状态维度和短序列常数项可能反转结果。
- **“Hybrid 自动兼得两边优点。”** 它也叠加 KV、State、Kernel、并行和调参复杂度。

## 复习

4. State Space Duality 说明了什么，又没有说明什么？
