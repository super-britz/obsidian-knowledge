# Transformer 架构学习地图

> [!abstract] 学习目标
> 以“文本如何在有限上下文和计算资源下，经过 Transformer 生成下一个 Token”为主线，形成能解释模型行为、预测工程限制并指导 LLM / Agent 决策的心智模型。

## 学习范围与取舍

- **优先目标**：理解 LLM 的输入、上下文处理、生成、训练与推理边界，并能把这些理解用于 RAG、工具调用、Agent 上下文和性能设计。
- **非当前目标**：从零训练基础模型、完整推导全部矩阵求导、为覆盖术语而逐章摘抄。
- **笔记规则**：按能独立形成“机制 → 约束 → 表现 → 工程决策”的概念组整理，而不是机械地一章一篇。

## 每个概念组的学习闭环

1. 从来源章节提取能支撑机制和边界的事实。
2. 不看原文，画出输入、关键过程和输出。
3. 写出至少一个限制或失败表现。
4. 连接到 LLM 应用或 Agent 的工程决策。
5. 用 [[_meta/templates/概念建模笔记检查清单|概念建模笔记检查清单]] 验收。
