# 线性变换：模型怎样重新组合 Token 的数字

> [!abstract] Token 在模型内部是一组数字。线性变换按照训练学到的权重重新组合这些数字，得到一种适合当前用途的新表示。矩阵乘法只是批量完成这种重新组合的计算方式。

> [!info] 放回完整生成链
> 线性变换不是单独一个处理阶段，而是遍布 Attention、FFN 和 LM Head。模型不断使用不同权重，把同一个隐藏状态转换成不同用途的表示。

## 作用是什么

一个 Token 的向量中混合着很多模型学习到的特征。线性变换会按照当前组件的需要，增强、减弱和重新组合这些特征。

```text
Token 当前表示
→ 使用一套训练学到的权重重新组合
→ 得到一种新表示
```

权重不是程序员手写的规则，而是在训练中根据预测误差逐渐调整出来的。

## 为什么同一个 Token 要变换多次

同一个隐藏状态，在不同地方承担的任务不同。例如 Attention 会使用三套不同权重生成：

```text
Q：当前要寻找什么信息
K：自己可以怎样被匹配
V：匹配后自己提供什么信息
```

Q、K、V 不是三份原始文本，而是同一个 Token 表示经过三套不同线性变换后得到的三个版本。

FFN 也会用线性变换展开和重新组合特征；LM Head 则用它把最终隐藏状态转换成词表中每个候选 Token 的分数。

## 矩阵乘法在这里做什么

模型需要同时处理很多 Token 和很多特征。矩阵乘法可以一次完成大量“按照权重重新组合数字”的计算。

第一次学习不需要手算矩阵，只需记住：

> **线性变换决定数字怎样重新组合，矩阵乘法负责高效执行。**

## 关键理解

- **输入和输出都是数字表示。** 文字早已在 Tokenization 和 Embedding 阶段变成数字。
- **不同权重产生不同用途的表示。** Q、K、V 的区别主要来自使用了不同权重。
- **训练修改权重，推理使用权重。** 一次普通聊天不会直接改变这些参数。
- **线性变换不等于完整理解。** 模型能力来自 Attention、FFN、非线性、残差和多层计算共同作用。

## 别误解

- **“权重就是人工规则。”** 权重是训练从大量样本中学到的数字。
- **“Q、K、V 是 Token 自带的三个属性。”** 它们是运行时通过不同权重计算出来的表示。
- **“线性变换会直接输出下一个 Token。”** 它只是改变表示；完整生成还需要多层 Transformer、LM Head 和解码。
