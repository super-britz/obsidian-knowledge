# 解码与采样策略：模型怎样选出下一个 Token

> [!abstract] 模型前向传播只给词表中的每个 Token 一个分数；解码策略决定怎样从这些候选中选出下一个 Token。它能调节稳定性、多样性、重复和输出长度，但不能补充知识、验证事实或赋予工具权限。

> [!info] 放回完整生成链
> `LM Head → logits → 调整与筛选候选 → 选择 Token → 追加并重复`。前端看到的流式文本，就是这条循环不断产生 Token 后再解码为字符。

## 一次 Token 选择发生什么

```text
词表 logits
→ Temperature 等参数调整分布
→ Top-K / Top-P 等策略缩小候选集合
→ Greedy 或随机采样选出一个 Token
→ 检查 EOS、Stop、长度等停止条件
→ 追加 Token，进入下一轮
```

不同框架对参数组合和执行顺序可能有差异，应以目标 API 文档为准。解码发生在推理阶段，不会修改模型参数。

## Greedy 和 Sampling 的区别

| 策略 | 怎样选择 | 优势 | 主要风险 |
| --- | --- | --- | --- |
| Greedy | 每一步都选当前最高分 Token | 简单、稳定、成本低 | 可能重复，也不保证整段最优 |
| Sampling | 按候选概率随机选择 | 输出更多样，能探索不同续写 | 同一输入可能不同，也会采到较差候选 |
| Beam Search | 同时保留多条高分序列 | 能发现开头分数不最高的整体候选 | 计算更贵，开放式对话未必受益 |

Greedy 是局部选择：当前每一步最高分，不等于整段回答的事实正确性或全局质量。

## Temperature、Top-K 与 Top-P

- **Temperature：** 调整分布的尖锐程度。较低时概率更集中，较高时更多候选有机会被采样；它不是正确性开关。
- **Top-K：** 每一步只保留分数最高的 K 个候选，再从中选择。
- **Top-P：** 从高到低累积概率，只保留累计达到阈值所需的最小候选集合；集合大小会随当前分布变化。

三者都是候选控制，不会修复错误上下文和幻觉。不要一次同时大幅修改多个参数，否则很难判断输出变化来自哪里。

## 重复控制与停止条件

重复惩罚、Frequency Penalty、Presence Penalty 等会降低某些已出现 Token 再次被选择的机会，但具体定义依赖服务商。惩罚过强可能破坏专有名词、代码变量和必要复述。

生成通常在以下任一条件满足时停止：

- 模型生成 EOS；
- 达到最大输出 Token；
- 命中 Stop Sequence；
- 请求被用户取消、超时或服务端中止。

前端不能假设每次都有自然结尾。流式 UI 要处理截断文本、不完整 Markdown / JSON、取消和重试；服务端还应区分正常停止、长度耗尽与错误中止。

## 结构化输出不是低温采样

需要 JSON 或工具参数时，优先使用服务支持的 Schema / Constrained Decoding，而不是只在 Prompt 里写“请返回 JSON”或把 Temperature 调低。

```text
模型生成
→ Schema 约束或解析
→ 类型与业务规则校验
→ 权限检查
→ 执行工具
→ 读取真实回执
```

Schema 只能约束结构。一个合法的 `{"amount": 100000}` 仍可能金额不合理、没有权限或基于错误事实。

## 前端项目怎样选择

| 场景 | 起始策略 | 还必须做什么 |
| --- | --- | --- |
| 分类、抽取、工具参数 | 较低随机性或结构化输出 | Schema、枚举和业务校验 |
| 普通问答与摘要 | 从服务默认值建立基线 | 检查证据、长度和重复 |
| 文案与创意候选 | 允许适度采样和多候选 | 人工选择、品牌与安全检查 |
| 数学、代码、规划 | 不靠随机性证明正确 | 计算器、测试、验证器或工具 |

没有通用的最佳参数。先固定模型和 Prompt，用真实失败样例一次只调整一个变量，并记录模型版本、解码配置和停止原因。

## 可复现不等于完全确定

固定随机种子有助于实验复现，但模型版本、硬件、框架后端和服务调度变化仍可能产生差异。即使使用 Greedy 或极低随机性，也不应把第三方模型 API 当作跨版本逐字不变的纯函数。

快照测试应关注结构、关键字段和业务指标；需要逐字稳定的固定文本应由代码或模板生成。

## 别误解

- **“Temperature 为 0 就不会幻觉。”** 它只减少采样随机性，不能补充证据。
- **“Top-P 越小越准确。”** 候选更少不等于事实更真。
- **“Seed 相同就永远得到相同文本。”** 可复现依赖完整运行环境和模型版本。
- **“合法 JSON 可以直接执行。”** 结构、语义、权限和真实执行结果是四个不同边界。
