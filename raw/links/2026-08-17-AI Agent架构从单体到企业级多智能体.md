该书定位为框架无关的 Agent 系统设计模式与生产实践资料，而非某个框架的 API 文档。首页将重点放在工具调用、上下文与记忆、单 Agent 推理、多 Agent 编排、生产架构、企业治理和前沿 Agent 实践。
