# AI Agent 架构：第 37 章 分层压缩

- **原文标题：** 第 37 章：分层压缩
- **URL：** https://waylandz.com/ai-agent-book/%E7%AC%AC37%E7%AB%A0-%E5%88%86%E5%B1%82%E5%8E%8B%E7%BC%A9/
- **访问日期：** 2026-08-19
- **资料类型：** 在线书籍章节页

## 来源摘要

本章讨论对仍留在 Prompt 的工具结果按年龄分层压缩。年龄只是“未来可能不再相关”的代理，不能代表真实价值；因此首次处理时将结果分为近期完整保留、中等年龄保留语义、陈旧结果仅留工具名/参数/体量等元数据。关键不是线性缩短，而是按未来价值改变保留的信息类型。已经进入中间层的结果保持字节稳定，不会随时间继续自动降为存根，以避免反复重写和缓存污染。

承载正文的工具（如读取、搜索、目录和浏览器结果）不能直接降为元数据，因为模型可能正围绕早期内容继续工作。通用压缩器应为这类工具设置“至少保留实质”的下限，并允许结构性页面快照等工具跳过微压缩。若任务的相关性不随年龄单调衰减，例如长期对比或回看早期堆栈，年龄分层就不是合适模型，应使用可按需取回的外溢。

语义压缩本身消耗模型调用，需设每趟的尝试次数上限；超出的候选使用零模型调用的机械截断。重写工具结果必须保持 tool_use 与 tool_result 配对，事前建立调用 ID 到工具元数据的映射，并记录每次分层重写对 Prompt Cache 的影响。短会话无需启用额外的分层机制。

## 使用边界

- 分层压缩是模型工作视图的预算优化，不是对长期记忆、审计记录或工具原文的删除策略。
- 年龄与相关性的关联只是一种经验代理；当早期信息可能被精确回看时，应保留可取回原文而非调节层级阈值。
- 公开源码中的层级距离、摘要长度和每趟上限属于有日期的实现快照；可迁移原则是“按信息价值分类、一次处理后稳定、正文工具有下限、重写可验证可观测”。
