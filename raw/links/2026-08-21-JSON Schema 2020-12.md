# JSON Schema 2020-12

- **机构：** JSON Schema
- **规范入口：** https://json-schema.org/specification
- **Core：** https://json-schema.org/draft/2020-12/json-schema-core
- **Validation：** https://json-schema.org/draft/2020-12/json-schema-validation
- **访问日期：** 2026-08-21
- **资料类型：** 官方规范与规范索引

## 来源摘要

JSON Schema 官方规范页在访问日将 2020-12 列为当前版本，并将规范分为 Core 与 Validation。Core 定义 Schema 的基础术语、方言、词汇表、引用和输出机制；Validation 定义对 JSON 实例作出结构性断言的关键字。

Schema 不是一组不带版本的通用规则。`$schema` 用来声明方言；不同词汇表和实现能力会影响实际行为。例如 2020-12 中 `format` 可以只是 Annotation，而完整的 Format-Assertion 支持是可选能力，不能只看到 `format: "email"` 就假定所有验证器都会拒绝不合格值。

## 使用边界

- JSON Schema 可以描述和验证可映射到 JSON 数据模型的结构，但不自动完成业务授权、数据库查询、并发判断或副作用恢复。
- 规范版本、方言与验证器能力需要一起固定和测试；不能把“Schema 文件存在”等同于“所有运行环境执行了同一组断言”。
- JSON Schema 是跨系统契约的一种实现；本知识页不会把它规定为所有前端边界的默认工具。
