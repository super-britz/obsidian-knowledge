# 长上下文注意力与位置编码原始论文

这组一手资料用于核验长上下文中的稀疏连接、线性 / 压缩记忆，以及位置编码与上下文扩展方案。

## Attention 与记忆

- Beltagy et al., *Longformer: The Long-Document Transformer*（2020）：https://arxiv.org/abs/2004.05150
- Zaheer et al., *Big Bird: Transformers for Longer Sequences*（2020）：https://arxiv.org/abs/2007.14062
- Katharopoulos et al., *Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention*（2020）：https://arxiv.org/abs/2006.16236
- Munkhdalai et al., *Leave No Context Behind: Efficient Infinite Context Transformers with Infini-attention*（2024）：https://arxiv.org/abs/2404.07143

## 位置表示与窗口扩展

- Vaswani et al., *Attention Is All You Need*（2017）：https://arxiv.org/abs/1706.03762
- Su et al., *RoFormer: Enhanced Transformer with Rotary Position Embedding*（2021）：https://arxiv.org/abs/2104.09864
- Press et al., *Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation*（2021）：https://arxiv.org/abs/2108.12409
- Chen et al., *Extending Context Window of Large Language Models via Positional Interpolation*（2023）：https://arxiv.org/abs/2306.15595
- Peng et al., *YaRN: Efficient Context Window Extension of Large Language Models*（2023）：https://arxiv.org/abs/2309.00071

## 使用边界

- 各论文的复杂度、质量与外推结果都有特定结构、任务、训练长度和硬件前提，不能跨模型直接当成保证。
- Sparse Attention 只有在实现能跳过无效连接时才节省实际计算；在稠密分数矩阵上加 Mask 只改变结果语义。
- Linear Attention 改写了相似度计算，不是标准 Softmax Attention 的无误差重排；Infini-attention 的固定跨 Segment 状态是压缩记忆，不保留所有 Token 的精确随机访问。
- RoPE、ALiBi、Position Interpolation 与 YaRN 改善的是位置表示或长度扩展条件，不会自动消除 Attention、KV Cache 和服务调度成本，也不保证模型能可靠使用窗口内任意信息。
