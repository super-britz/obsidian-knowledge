# Prompt 工程原始资料

这组一手资料用于核验 In-Context Learning、Chain-of-Thought、Self-Consistency、Tree-of-Thought 和间接 Prompt Injection 的机制与实验边界。

## 来源

- Brown et al., *Language Models are Few-Shot Learners*（2020）：https://arxiv.org/abs/2005.14165
- Wei et al., *Chain-of-Thought Prompting Elicits Reasoning in Large Language Models*（2022）：https://arxiv.org/abs/2201.11903
- Wang et al., *Self-Consistency Improves Chain of Thought Reasoning in Language Models*（2022）：https://arxiv.org/abs/2203.11171
- Yao et al., *Tree of Thoughts: Deliberate Problem Solving with Large Language Models*（2023）：https://arxiv.org/abs/2305.10601
- Greshake et al., *Not what you've signed up for: Compromising Real-World LLM-Integrated Applications with Indirect Prompt Injection*（2023）：https://arxiv.org/abs/2302.12173

## 使用边界

- Few-shot、CoT、Self-Consistency 与 ToT 论文中的收益来自特定模型、数据集、Prompt、采样和评分方法，不能转换为跨任务通用的提升百分比。
- In-Context Learning 通过当前输入中的任务描述和示例改变条件生成，不更新模型参数；示例既能传递标签和格式，也可能引入顺序、措辞和类别分布偏差。
- CoT 论文说明中间推理步骤可改善部分算术、常识和符号推理任务，但不证明每个中间文本都忠实反映模型内部计算，也不保证适用于简单任务或所有模型。
- Self-Consistency 对多条采样路径的最终答案聚合；多数票不是经过校准的置信度，相关性错误也不会因重复采样自动消失。
- ToT 把生成、候选评估、搜索和回溯组成推理时算法，不能只理解成一句更长的 Prompt；分支数量和深度会增加延迟与 Token 成本。
- 间接 Prompt Injection 利用应用把外部数据和可执行指令放进同一模型上下文的边界混淆。自然语言提醒可以降低部分风险，但不能代替权限控制、工具参数验证和高风险操作确认。
