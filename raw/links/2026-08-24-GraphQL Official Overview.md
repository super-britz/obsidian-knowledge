# GraphQL：官方概览

- **机构：** GraphQL Foundation
- **URL：** https://graphql.org/
- **访问日期：** 2026-08-24
- **资料类型：** 官方项目概览

## 来源摘要

GraphQL 官方将其定义为 API 查询语言和服务端运行时。服务通过强类型 Schema 发布可查询能力，客户端按字段指定响应形状；一次查询可以沿数据关系获取多个资源，从而减少固定端点常见的过度获取、不足获取和多次请求。

GraphQL 描述的是客户端怎样表达数据需求以及服务怎样执行这类查询，不绑定数据库或存储引擎。其 Schema、Resolver、权限、成本控制、缓存、数据所有权和运行责任仍需由具体系统设计。

## 使用边界

- GraphQL 可以作为 BFF、共享 API 层或领域服务的接口机制；选择 GraphQL 本身不决定它属于哪一层、由谁拥有。
- 字段级裁剪可以缓解数据形状差异，但不会自动解决跨服务失败、N+1、授权、限流和发布兼容。
- 是否因此不再需要独立 BFF，应依据客户端差异和团队边界判断，而不是由协议名称推断。
