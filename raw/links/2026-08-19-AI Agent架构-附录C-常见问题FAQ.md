# AI Agent 架构：附录 C 常见问题 FAQ

- **原文标题：** 附录 C：常见问题 FAQ
- **URL：** https://waylandz.com/ai-agent-book/%E9%99%84%E5%BD%95C-%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98FAQ/
- **访问日期：** 2026-08-19
- **资料类型：** 在线书籍附录页

## 来源摘要

原文覆盖入门、架构选型、成本与性能、安全治理、框架比较和实践调试。反复出现的高价值问题是：单 Agent 与多 Agent 的边界、Planning 与 ReAct 的关系、何时需要持久化工作流、如何限制 Token/迭代/超时、如何分层使用模型、如何隔离执行和防御 Prompt Injection，以及如何按“输入 → 工具 → 输出”排查故障。

FAQ 的可迁移价值主要是暴露误解：复杂架构不是默认答案；预算、最大迭代和超时各自限制不同的资源故障；MCP 解决互操作而非工具调用的必要条件；沙箱、授权和 Prompt 防注入需要分层处理。框架对比、安装命令、端口和具体数值属于当时的实现快照。

## 使用边界

- FAQ 应将问题归回相应的机制页或模式选择页，而不是复制为与正式笔记竞争的另一套答案库。
- 与特定框架、部署命令、端口、版本或价格有关的回答需要以当前官方文档和实际环境复核。
- 单一“最佳实践”通常不成立；应明确任务风险、完成证据、成本/延迟目标与运行边界后再选择控制措施。
