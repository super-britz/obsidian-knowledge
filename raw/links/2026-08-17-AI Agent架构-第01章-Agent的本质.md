# AI Agent 架构：第 1 章 Agent 的本质

## 来源摘要

本章将 Agent 定义为：给定目标、工具箱和边界（预算、权限、审批、沙箱）后，能够在循环中推进任务，直到完成或停止的 AI 系统。它与 Chatbot 的差异不在于更会聊天，而在于能否在授权和确认机制下安全执行行动，并保留过程可追溯性。

原文将 Agent 概括为 LLM、Tools、Memory 与 Autonomy 四部分，并把 Guardrails 视为生产上线所需的预算、权限、审批、审计和沙箱层。章节还对比传统确定性软件与 Agent 的概率性执行路径：模型判断、工具调用和观察结果会使运行路径随状态而变化。

本章给出 L0～L5 的自主性分级，并明确这只是作者用于讨论的直觉尺度、不是学术标准；本书重点讨论 L2～L4。适用任务具有目标明确、步骤可拆、结果可验证、信息可获得和重复价值高等特征。付款、发布、删除、群发等高风险或不可逆操作需要人工确认。
