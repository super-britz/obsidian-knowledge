# web.dev：Core Web Vitals Thresholds

- **机构：** Google / web.dev
- **URL：** https://web.dev/articles/defining-core-web-vitals-thresholds
- **访问日期：** 2026-08-24
- **资料类型：** 官方指标说明

## 来源摘要

截至访问日期，Core Web Vitals 包含 LCP、INP 和 CLS：分别关注主要内容呈现、交互响应和视觉稳定。官方“Good”阈值为 LCP 不超过 2.5 秒、INP 不超过 200 毫秒、CLS 不超过 0.1，并以页面访问样本的第 75 百分位判断整体表现。

文档说明这些阈值同时考虑用户体验研究与现实可达性，不是物理定律；用户感知随场景连续变化，也不存在跨所有页面、设备与任务都适用的唯一时间点。

## 使用边界

- Core Web Vitals 是通用体验信号，不覆盖业务数据是否正确、特定 Feature 是否就绪或关键任务是否完成。
- 官方阈值适合做公共基线，产品仍需按关键旅程、设备、网络、地域和业务后果建立自己的预算。
- 平均值会隐藏长尾体验；即使采用 P75，也应按关键人群查看更高分位和失败率。
