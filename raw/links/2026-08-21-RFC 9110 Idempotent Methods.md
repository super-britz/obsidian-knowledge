# RFC 9110：Idempotent Methods

- **机构：** IETF / RFC Editor
- **URL：** https://www.rfc-editor.org/rfc/rfc9110.html#section-9.2.2
- **访问日期：** 2026-08-21
- **资料类型：** HTTP 语义标准

## 来源摘要

RFC 9110 将幂等方法定义为：多次相同请求对服务端产生的预期效果，与一次请求的预期效果相同。规范定义 PUT、DELETE 和安全方法为幂等，并说明幂等请求在通信失败、客户端尚未读到响应时可以重复发送，即使第一次请求可能已经成功。

规范同时要求客户端不要自动重试非幂等方法，除非能确认该请求的实际语义是幂等的，或者能确定原请求从未被应用。重复请求的响应可以不同，幂等约束的是预期服务端效果。

## 使用边界

- HTTP 方法语义不能代替业务实现；创建订单等写操作仍需明确重复请求的处理规则。
- POST 并非天然不可重试：应用可以通过操作身份、去重记录和结果查询把特定命令设计为可安全重试。
- 幂等避免重复业务效果，不等于所有日志、计数或响应字节都完全相同。
