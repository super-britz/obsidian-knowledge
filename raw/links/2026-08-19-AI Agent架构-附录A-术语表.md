# AI Agent 架构：附录 A 术语表

- **原文标题：** 附录 A：术语表 (Terminology Glossary)
- **URL：** https://waylandz.com/ai-agent-book/%E9%99%84%E5%BD%95A-%E6%9C%AF%E8%AF%AD%E8%A1%A8/
- **访问日期：** 2026-08-19
- **资料类型：** 在线书籍附录页

## 来源摘要

原文按字母顺序汇集 Agent、工具调用、上下文与记忆、工作流、多 Agent、可观测性、预算与安全等术语；每项给出中英文名称、简短定义、示例、相关术语和关联章节。它的主要用途是快速定位概念，而不是替代各章节中的机制、约束和工程决策。

其中最容易造成架构误判的不是某个词的中文翻译，而是边界混淆：Context 与 Memory 的生命周期不同；Tool、Skill 与 MCP 分别是行动能力、任务能力封装和互操作协议；DAG、Orchestrator 与 Handoff 分别解决依赖调度、控制权协调和任务交接；Policy、Guardrail 与 Sandbox 则分别约束决策、输入输出和实际执行能力。

## 使用边界

- 术语表适合查定义与建立链接，不应复制成与正式概念页并列的第二套知识体系。
- 定义、框架名和示例具有时效性；遇到架构选择，应优先回到相关概念页确认因果链与适用边界。
- 术语相近不代表可互换：必须按状态、控制权、执行能力和生命周期区分。
