# 文本生成解码与结构化输出官方文档

这组官方资料用于核验文本生成中的 Greedy、Sampling、Beam Search、输出长度、停止条件与结构化输出边界。

## 来源

- Hugging Face Transformers，*Generation strategies*：https://huggingface.co/docs/transformers/main/en/generation_strategies
- Hugging Face Transformers，*GenerationConfig*：https://huggingface.co/docs/transformers/main/en/main_classes/text_generation#transformers.GenerationConfig
- OpenAI API，*Structured model outputs*：https://developers.openai.com/api/docs/guides/structured-outputs
- PyTorch，*Reproducibility*：https://docs.pytorch.org/docs/stable/notes/randomness.html

## 使用边界

- 解码策略在推理时从模型输出分布中选择 Token，不修改可训练参数；不同策略会影响重复、多样性、延迟和最终文本。
- Greedy 每步选择当前最高概率 Token；Sampling 按分布随机选择；Beam Search 同时保留多个序列假设。它们的适用性取决于任务和模型，不存在跨任务固定最优方案。
- Temperature、Top-K、Top-P、重复惩罚和停止条件的精确参数名、默认值及组合顺序依赖模型服务或框架；本地笔记只保留通用机制，使用时必须核对目标 API。
- Structured Outputs 可以约束生成结果匹配支持范围内的 Schema；Schema 一致不证明字段事实正确、业务合法、拥有执行权限或工具实际成功。
- 固定随机种子有助于复现实验，但框架版本、硬件、后端算法和并发服务可能仍带来差异；确定性不能脱离具体运行环境承诺。
